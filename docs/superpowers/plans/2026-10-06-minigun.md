# Minigun: plan de implementación

> **Para agentes:** SUB-HABILIDAD OBLIGATORIA: usar superpowers:executing-plans (el usuario elige siempre la ejecución nativa) o superpowers:subagent-driven-development para ejecutar este plan tarea a tarea. Los pasos usan casillas (`- [ ]`).

**Objetivo:** que CJ lleve y dispare la minigun de GTA SA (arma 38, modelo 362), con su modelo real en la mano y daño a mobs y bloques por el camino de M3.

**Arquitectura:** la minigun entra por el camino de las armas de M2 y M3 sin protocolo nuevo: una entrada en `weapons.json`, `WeaponModelId(38) = 362` en el puente, `minigun` en el conversor de modelos. El conversor gana dos capacidades porque el modelo real de la minigun las necesita: un modelo estático con **dos texturas** (el cuerpo y el cinturón de balas, material por triángulo) y el **ensamblado de las piezas hijas** (el bloque de cañones cuelga de un marco hijo y hoy se descarta), con el modelo fijo que decidió el usuario.

**Tecnologías:** Python 3 (conversor, `unittest`), C++ del puente (pruebas nativas con `tools/run_native_tests.sh`), Java 21 / Fabric 1.21.1 con Yarn (JUnit 5), GTA SA 1.0 US bajo Wine.

**Spec:** `docs/superpowers/specs/2026-10-06-minigun-design.md`. Contexto: `docs/m2-results.md`, `docs/m3-results.md`.

## Global Constraints

- Protocolo v2 sin cambios (`State` 72 B, `Echo` 32 B, `Pose` 24+32×N, `Shot` 24 B).
- Modelos de arma: `.glb` de **una articulación** (mano derecha, nodo 24); `WeaponModelLoader` rechaza otro número. Se admiten **varias mallas y varias texturas** (el cargador y `WeaponRig` ya dibujan una malla por parte con su imagen).
- Un modelo de arma sin modelo conocido en `WeaponModelId` no se da nunca (GTA se cae sin el modelo cargado por *streaming*).
- Las seis armas de M2 no cambian de aspecto: el ensamblado de piezas hijas es **opcional** y solo se activa para `minigun`.
- El paquete `dev.cjmc.combat` no usa clases de cliente.
- Convenciones del repo: TDD con el rojo observado, mutaciones comprobadas por el arnés (el fallo debe ser de la prueba, no de compilación), commits con `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`, comentarios en inglés en el código, documentos en español.
- Hechos medidos en la instalación real (`GTA San Andreas/models/gta3.img`): `minigun.dff` tiene 3 atómicos: marco 0 (raíz, identidad) con la geometría de 582 triángulos y dos materiales (`bulletbelt`: 16 triángulos, `minigun_2`: 566); marco 1 hijo en (1.36, −0.05, 0.47) con el fogonazo (`muzzle_texture4`, 464 triángulos); marco 2 hijo en (0.83, 0.0, 0.23) con 208 triángulos de `minigun_2` (el bloque de cañones). También existen `minigun2.dff` y `minigun_base.dff`. `minigun.txd` contiene `bulletbelt` y `minigun_2`.
- Pruebas y comandos: Python `cd tools && python3 -B -m unittest discover -s tests`; nativas `bash tools/run_native_tests.sh`; Java `cd cj-fabric && ./gradlew test --console=plain`. Arnés de mutaciones: `/tmp/claude-1000/mutj.py <json>` con entradas `[fichero, original, mutante]` (base `cj-fabric/src/main/java/dev/cjmc/`; para Python y C++ se adapta la base o se muta a mano y se restaura con `git checkout`).

```python
def assembled_dff(body_geometry, part_geometry, flash_geometry, part_pos=(0.0, 0.0, 0.0), part_rot=IDENTITY3):
    """A weapon with a body on the root frame, a flash on a child frame and one more part (the barrels of a minigun) on another
    child frame, moved and rotated by `part_pos` and `part_rot` (nine floats, the RenderWare right, up and at vectors).
    Geometry 0 is the flash, 1 the part, 2 the body; the atomics come in that order, like in the real file."""
    clump_struct = struct_chunk(struct.pack("<III", 3, 0, 0))
    frames = struct.pack("<I", 3)
    frames += struct.pack("<12f", *IDENTITY3, 0.0, 0.0, 0.0) + struct.pack("<iI", -1, 0)
    frames += struct.pack("<12f", *IDENTITY3, 0.4, 0.0, 0.1) + struct.pack("<iI", 0, 0)
    frames += struct.pack("<12f", *part_rot, *part_pos) + struct.pack("<iI", 0, 0)
    frame_list = chunk(0x0E, struct_chunk(frames) + extension() + extension() + extension())
    geometry_list = chunk(0x1A, struct_chunk(struct.pack("<I", 3)) + flash_geometry + part_geometry + body_geometry)
    atomic_flash = chunk(0x14, struct_chunk(struct.pack("<IIII", 1, 0, 5, 0)) + extension())
    atomic_part = chunk(0x14, struct_chunk(struct.pack("<IIII", 2, 1, 5, 0)) + extension())
    atomic_body = chunk(0x14, struct_chunk(struct.pack("<IIII", 0, 2, 5, 0)) + extension())
    return chunk(0x10, clump_struct + frame_list + geometry_list + atomic_flash + atomic_part + atomic_body + extension()) + b"\0" * 24
```

```python
@dataclass(frozen=True)
class StaticPart:
    positions: list
    normals: list
    uvs: list
    triangles: list
    texture: str  # the texture of the first group
    groups: tuple = ()  # ((texture name, triangles), ...): the triangles that use each texture, in order of first use


def _frames(data, clump):
    st = first(data, first(data, clump, FRAME_LIST), STRUCT)
    count = struct.unpack_from("<I", data, st.start)[0]
    frames = []
    for i in range(count):
        values = struct.unpack_from("<12f", data, st.start + 4 + i * 56)
        parent = struct.unpack_from("<i", data, st.start + 4 + i * 56 + 48)[0]
        frames.append((parent, values))
    return frames


def _frame_world(frames, index):
    """The matrix of a frame in the root's space, as (right, up, at, position): a point p goes to p.x*right + p.y*up + p.z*at + position."""
    parent, values = frames[index]
    right, up, at, pos = values[0:3], values[3:6], values[6:9], values[9:12]
    if parent < 0:
        return right, up, at, pos
    if not 0 <= parent < index:
        raise FormatError("a frame has an impossible parent")
    pr, pu, pa, pp = _frame_world(frames, parent)
    return tuple(_apply(pr, pu, pa, (0, 0, 0), v) for v in (right, up, at)) + (_apply(pr, pu, pa, pp, pos),)


def _apply(right, up, at, pos, p):
    return tuple(p[0] * right[k] + p[1] * up[k] + p[2] * at[k] + pos[k] for k in range(3))


def _static_geometry(data, geometry):
    """(positions, normals, uvs, triangles, texture name of each triangle) of one geometry."""
    positions, normals, uvs, triangles, _count, materials = _read_geometry(data, geometry, allow_tristrip=True, with_materials=True)
    textures = _material_textures(data, geometry)
    names = []
    for m in materials:
        if m >= len(textures):
            raise FormatError(f"a triangle uses the material {m} but the geometry has {len(textures)}")
        if textures[m] is None:
            raise FormatError(f"the material {m} of the geometry has no texture")
        names.append(textures[m])
    if not names:
        raise FormatError("the geometry has no textured material")
    return positions, normals, uvs, triangles, names


def _groups(triangles, names):
    order = []
    for name in names:
        if name not in order:
            order.append(name)
    return tuple((name, tuple(t for t, n in zip(triangles, names) if n == name)) for name in order)


def parse_static_part(data, children=False):
    """The solid geometry of a model with no skeleton (a weapon): the atomic that hangs from the root frame.
    The muzzle flash is another atomic on a child frame and is left out. With `children`, the other atomics are added too
    (moved by their frames), except any that use a texture whose name contains "muzzle": that is how a minigun keeps its barrels."""
    clump = first(data, root(data), CLUMP)
    frames = _frames(data, clump)
    geometries = all_of(data, first(data, clump, GEOMETRY_LIST), GEOMETRY)
    atomics = []
    for atomic in all_of(data, clump, ATOMIC):
        st = first(data, atomic, STRUCT)
        frame, geometry = struct.unpack_from("<II", data, st.start)
        if frame < len(frames) and geometry < len(geometries):
            atomics.append((frame, geometries[geometry]))
    body = next(((f, g) for f, g in atomics if frames[f][0] == -1), None)
    if body is None:
        raise FormatError("no geometry hangs from the root frame")
    identity = (1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0)
    if any(abs(v - e) > 1e-4 for v, e in zip(frames[body[0]][1], identity)):
        raise FormatError("the root frame of the model is not the identity; the model would need a transform")
    positions, normals, uvs, triangles, names = _static_geometry(data, body[1])
    if children:
        count = len(positions)
        normals = list(normals) or [(0.0, 0.0, 1.0)] * count
        uvs = list(uvs) or [(0.0, 0.0)] * count
        positions, triangles, names = list(positions), list(triangles), list(names)
        for frame, geometry in atomics:
            if (frame, geometry) == body or any("muzzle" in n for n in _material_textures(data, geometry) if n):
                continue
            p, n, u, t, tn = _static_geometry(data, geometry)
            right, up, at, pos = _frame_world(frames, frame)
            base = len(positions)
            positions += [_apply(right, up, at, pos, v) for v in p]
            normals += [_apply(right, up, at, (0, 0, 0), v) for v in n] if n else [(0.0, 0.0, 1.0)] * len(p)
            uvs += list(u) if u else [(0.0, 0.0)] * len(p)
            triangles += [(a + base, b + base, c + base) for a, b, c in t]
            names += tn
    groups = _groups(triangles, names)
    return StaticPart(positions, normals, uvs, triangles, groups[0][0], groups)
```

```python
#!/usr/bin/env python3
"""Stand-in for the Minecraft mod: holds the aim and fire intents with one weapon and reports the rounds per second GTA fires.
Usage: gun_probe.py [weapon id, default 38] [seconds, default 6]. GTA must be running with a game loaded and nothing else
talking to the bridge (close Minecraft)."""
import socket
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent / "protocol"))
import cjproto as p  # noqa: E402

GTA_ADDR = ("127.0.0.1", 34560)
ECHO_ADDR = ("127.0.0.1", 34561)
RATE_HZ = 60.0


def main(argv):
    weapon = int(argv[1]) if len(argv) > 1 else 38
    seconds = float(argv[2]) if len(argv) > 2 else 6.0
    rx = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    rx.bind(ECHO_ADDR)
    rx.setblocking(False)
    tx = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    seq = 0
    shots = []  # (gta_time_ms, shot_seq, rounds)
    held = 0

    def send(intents):
        nonlocal seq
        state = p.State(seq=seq, ts_ms=int(time.monotonic() * 1000) & 0xFFFFFFFF, pos=(100.0, 64.0, 100.0), vel=(0.0, 0.0, 0.0),
                        yaw=0.0, pitch=0.0, flags=p.FLAG_ON_GROUND, intents=intents, weapon=weapon, aim=(0.0, 1.6, 20.0))
        tx.sendto(p.pack_state(state), GTA_ADDR)
        seq += 1

    def drain():
        nonlocal held
        while True:
            try:
                data, _ = rx.recvfrom(4096)
            except BlockingIOError:
                return
            try:
                shots.append((lambda s: (s.gta_time_ms, s.shot_seq, s.rounds))(p.unpack_shot(data)))
                continue
            except ValueError:
                pass
            try:
                held = p.unpack_echo(data).weapon_held
            except ValueError:
                pass

    print("holding the weapon for 3 s (aim only), then aim + fire for %.0f s ..." % seconds)
    for phase, intents, length in (("equip", 0, 3.0), ("fire", p.INTENT_AIM | p.INTENT_FIRE, seconds)):
        start = time.monotonic()
        next_send = start
        while time.monotonic() - start < length:
            send(intents)
            drain()
            next_send += 1.0 / RATE_HZ
            time.sleep(max(0.0, next_send - time.monotonic()))
        if phase == "equip":
            shots.clear()
    send(0)
    time.sleep(0.2)
    drain()
    print("weapon held according to GTA:", held)
    if len(shots) < 2:
        print("FAIL: fewer than two shot events (is the weapon held? is the game loaded?)")
        return 2
    first, last = shots[0], shots[-1]
    total = last[1] - first[1] + first[2]
    span_s = max(1e-3, (last[0] - first[0]) / 1000.0)
    biggest = max(r for _, _, r in shots)
    print(f"{len(shots)} shot events, {total} rounds over {span_s:.2f} s of GTA time = {total / span_s:.1f} rounds/s; "
          f"most rounds in one event: {biggest}")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```
