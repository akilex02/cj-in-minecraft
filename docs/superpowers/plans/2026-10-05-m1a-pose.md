# CJ en Minecraft — M1a: pose — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que el plugin de GTA mueva a CJ con una animación real según la velocidad y las acciones de Minecraft (parado, caminar, correr, sprint, salto) y le mande a Minecraft los huesos de CJ en un nuevo paquete `Pose`.

**Architecture:** CJ se queda de pie en un punto fijo del suelo de GTA con física normal; el plugin le da el "mando" desde un segundo hook (la llamada a `CPad::UpdatePads` dentro de `CGame::Process`) y, tras `Process`, lo devuelve al punto fijo y exporta sus huesos relativos al propio CJ. Toda la lógica vive en cabeceras puras con pruebas nativas; el código que toca memoria viva de GTA queda en `hook.cpp` y `bridge.cpp`.

**Tech Stack:** C++20 (clang++ nativo para las pruebas; `i686-w64-mingw32-g++` para el `.asi`), Python 3 `unittest`, CMake + Ninja, Wine 11.

**Spec:** `docs/superpowers/specs/2026-10-05-m1-cj-visible-design.md` (secciones 2, 4 y 7), que refina `2026-10-05-cj-in-minecraft-design.md`.

**Alcance de este plan:** solo M1a. M1b (conversor), M1c (render en Minecraft), M2, M3 y M4 tendrán cada uno su plan.

## Global Constraints

- Un solo jugador y sin conexión; todo el tráfico va por `127.0.0.1`, UDP, little-endian, con `magic` y `versión` en cada paquete. Puertos: GTA 34560, Minecraft 34561.
- Minecraft 1.21.1 con Fabric, Java 21 (este plan no toca el mod de Minecraft).
- `GTA San Andreas/gta_sa.exe` de 14,383,616 bytes. El plugin **no sustituye funciones del juego**: solo redirige llamadas (`call rel32`).
- CJ conserva **colisión y gravedad normales**; nunca se llama a `CPed::Teleport` (cancela las tareas y con ellas la animación).
- Los huesos se exportan en el espacio del propio CJ (sin su posición ni su giro). Máximo 48 huesos por paquete.
- Mientras haya enganche, `CPopulation::PedDensityMultiplier` y `CCarCtrl::CarDensityMultiplier` valen 0; al soltar se restauran.
- Si no llega estado en 1000 ms, el plugin suelta todo: restaura densidades y deja de escribir el mando (el usuario recupera el control).
- Los assets del juego y todo lo derivado no entran al repositorio.
- Hay git: un commit por tarea, con la línea `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

Entradas y condiciones que el spec implica pero que las pruebas de cada tarea no cubrirían por sí solas. Cada una tiene su prueba en la tarea indicada.

1. Jerarquía de huesos ausente, con 0 nodos o con más de 48 (CJ sin dibujar, pantalla de carga): no se manda `Pose` y no hay fallo — Task 2 y Task 5.
2. Matrices de hueso con escala o degeneradas: el cuaternión sale unitario y nunca `NaN` — Task 2.
3. CJ dentro de un vehículo: no se toca el mando, ni se mantiene el escenario, ni se tocan las densidades; si entra mientras estaba enganchado, se suelta — Task 5.
4. Expiración: se restauran las densidades y se deja de escribir el mando — Task 5.
5. Otro plugin que pisa cualquiera de las dos llamadas: sin recursión infinita y sin sacar de la cadena a un tercer plugin — Task 4.
6. El salto solo se pulsa al despegar del suelo de verdad: no se repite en el aire ni se dispara si el primer paquete ya está en el aire — Task 3.
7. Lecturas rotas de la llamada mientras otro plugin la reescribe: no se actúa con una sola lectura inestable — Task 4.

```python
def pack_pose(pose):
    if len(pose.bones) > POSE_MAX_BONES:
        raise ValueError(f"too many bones: {len(pose.bones)}")
    out = _HEADER.pack(MAGIC, VERSION, TYPE_POSE) + _POSE.pack(
        pose.ack_seq, pose.gta_time_ms, pose.flags, len(pose.bones), 0)
    for b in pose.bones:
        out += _BONE.pack(b.node_id, *b.pos, *b.quat)
    return out


def unpack_pose(data):
    if len(data) < POSE_HEADER_SIZE:
        raise ValueError(f"pose too short: {len(data)} bytes")
    magic, version, ptype = _HEADER.unpack_from(data, 0)
    if magic != MAGIC:
        raise ValueError("bad magic")
    if version != VERSION:
        raise ValueError(f"unsupported version {version}")
    if ptype != TYPE_POSE:
        raise ValueError(f"unexpected packet type {ptype}")
    ack, gta_time, flags, count, _reserved = _POSE.unpack_from(data, _HEADER.size)
    if count > POSE_MAX_BONES:
        raise ValueError(f"too many bones: {count}")
    if len(data) != POSE_HEADER_SIZE + count * BONE_SIZE:
        raise ValueError(f"expected {POSE_HEADER_SIZE + count * BONE_SIZE} bytes for {count} bones, got {len(data)}")
    bones = []
    for i in range(count):
        node_id, px, py, pz, qx, qy, qz, qw = _BONE.unpack_from(data, POSE_HEADER_SIZE + i * BONE_SIZE)
        bones.append(Bone(node_id, (px, py, pz), (qx, qy, qz, qw)))
    return Pose(ack, gta_time, tuple(bones), flags)
```

```cpp
#pragma once
#include <cmath>
#include <cstddef>
#include <cstdint>

#include "protocol.h"

namespace cj {

// Same layout as RwMatrix and as the matrix of a CPlaceable: three basis vectors and the position.
struct RwMat {
    float right[3];
    uint32_t flags;
    float up[3]; // the entity's forward direction
    uint32_t pad1;
    float at[3]; // the entity's up direction
    uint32_t pad2;
    float pos[3];
    uint32_t pad3;
};
static_assert(sizeof(RwMat) == 64);

// A ped's bone matrices (world space) and their node ids, as read from the RpHAnimHierarchy.
struct Skeleton {
    const RwMat* matrices = nullptr;
    int32_t ids[kMaxBones]{};
    int count = 0;
};

struct Quat {
    float x, y, z, w;
};

inline float Dot3(const float a[3], const float b[3]) { return a[0] * b[0] + a[1] * b[1] + a[2] * b[2]; }

// Unit quaternion of the rotation whose columns are the basis vectors (right, up, at).
// Normalises its result, and returns the identity if the basis is degenerate.
inline Quat QuatFromBasis(const float right[3], const float up[3], const float at[3]) {
    if (Dot3(right, right) < 1e-8f || Dot3(up, up) < 1e-8f || Dot3(at, at) < 1e-8f) {
        return {0, 0, 0, 1}; // degenerate basis
    }
    const float m00 = right[0], m10 = right[1], m20 = right[2];
    const float m01 = up[0], m11 = up[1], m21 = up[2];
    const float m02 = at[0], m12 = at[1], m22 = at[2];
    Quat q{0, 0, 0, 1};
    const float trace = m00 + m11 + m22;
    if (trace > 0.0f) {
        const float s = std::sqrt(trace + 1.0f) * 2.0f;
        q = {(m21 - m12) / s, (m02 - m20) / s, (m10 - m01) / s, 0.25f * s};
    } else if (m00 > m11 && m00 > m22) {
        const float s = std::sqrt(1.0f + m00 - m11 - m22) * 2.0f;
        q = {0.25f * s, (m01 + m10) / s, (m02 + m20) / s, (m21 - m12) / s};
    } else if (m11 > m22) {
        const float s = std::sqrt(1.0f + m11 - m00 - m22) * 2.0f;
        q = {(m01 + m10) / s, 0.25f * s, (m12 + m21) / s, (m02 - m20) / s};
    } else {
        const float s = std::sqrt(1.0f + m22 - m00 - m11) * 2.0f;
        q = {(m02 + m20) / s, (m12 + m21) / s, 0.25f * s, (m10 - m01) / s};
    }
    const float len = std::sqrt(q.x * q.x + q.y * q.y + q.z * q.z + q.w * q.w);
    if (!(len > 1e-6f) || !std::isfinite(len)) {
        return {0, 0, 0, 1};
    }
    return {q.x / len, q.y / len, q.z / len, q.w / len};
}

// Converts every bone from world space to the ped's own frame (X right, Y forward, Z up) and fills the packet.
// Returns false, leaving the bones untouched, when there is no usable skeleton.
inline bool BuildPose(PosePacket& out, uint32_t ackSeq, uint32_t gtaTimeMs, const RwMat& ped, const Skeleton& skel) {
    if (!skel.matrices || skel.count <= 0 || skel.count > static_cast<int>(kMaxBones)) {
        return false;
    }
    InitPose(out, ackSeq, gtaTimeMs);
    out.head.boneCount = static_cast<uint16_t>(skel.count);
    for (int i = 0; i < skel.count; i++) {
        const RwMat& b = skel.matrices[i];
        const float d[3] = {b.pos[0] - ped.pos[0], b.pos[1] - ped.pos[1], b.pos[2] - ped.pos[2]};
        BoneRecord& rec = out.bones[i];
        rec.nodeId = skel.ids[i];
        rec.pos[0] = Dot3(d, ped.right);
        rec.pos[1] = Dot3(d, ped.up);
        rec.pos[2] = Dot3(d, ped.at);
        // each bone axis, expressed in the ped's frame
        const float r[3] = {Dot3(b.right, ped.right), Dot3(b.right, ped.up), Dot3(b.right, ped.at)};
        const float u[3] = {Dot3(b.up, ped.right), Dot3(b.up, ped.up), Dot3(b.up, ped.at)};
        const float a[3] = {Dot3(b.at, ped.right), Dot3(b.at, ped.up), Dot3(b.at, ped.at)};
        const Quat q = QuatFromBasis(r, u, a);
        rec.quat[0] = q.x;
        rec.quat[1] = q.y;
        rec.quat[2] = q.z;
        rec.quat[3] = q.w;
    }
    return true;
}

} // namespace cj
```

```cpp
#pragma once
#include <cmath>
#include <cstdint>
#include <cstring>

#include "ped_layout.h"
#include "protocol.h"

namespace cj {

// What to write into CPad::Pads[0].NewState so GTA animates CJ like the Minecraft player moves.
struct PadCommand {
    bool active = false;
    int16_t stickX = 0;
    int16_t stickY = 0; // -128 = forward
    int16_t walk = 0;   // m_bPedWalk
    int16_t cross = 0;  // sprint
    int16_t square = 0; // jump
};

class PadDriver {
public:
    static constexpr float kMoveThreshold = 0.3f; // blocks/s of horizontal speed
    static constexpr float kJumpMinVy = 2.0f;     // blocks/s of upward speed that counts as a jump

    void OnState(const StatePacket& s) {
        const float vx = s.vel[0];
        const float vy = s.vel[1];
        const float vz = s.vel[2];
        speed_ = std::sqrt(vx * vx + vz * vz);
        sneak_ = (s.flags & kFlagSneak) != 0;
        sprint_ = (s.flags & kFlagSprint) != 0;
        const bool onGround = (s.flags & kFlagOnGround) != 0;
        if (haveState_ && prevOnGround_ && !onGround && vy > kJumpMinVy) {
            jumpPending_ = true;
        }
        prevOnGround_ = onGround;
        haveState_ = true;
    }

    // One call per game frame; the jump pulse and the sprint mashing advance with each call.
    PadCommand Command() {
        PadCommand c;
        if (!haveState_) {
            return c;
        }
        c.active = true;
        if (speed_ >= kMoveThreshold) {
            c.stickY = -128;
            c.walk = sneak_ ? 1 : 0;
            if (sprint_ && !sneak_) {
                sprintOn_ = !sprintOn_;
                c.cross = sprintOn_ ? 1 : 0;
            }
        }
        if (jumpPending_) {
            c.square = 1;
            jumpPending_ = false;
        }
        return c;
    }

    void Reset() { *this = PadDriver{}; }

private:
    bool haveState_ = false;
    float speed_ = 0.0f;
    bool sneak_ = false;
    bool sprint_ = false;
    bool prevOnGround_ = false;
    bool jumpPending_ = false;
    bool sprintOn_ = false;
};

// Writes the command into a CPad (raw memory). Leaves every field it does not own alone.
inline void ApplyPad(uint8_t* pad, const PadCommand& c) {
    if (!c.active) {
        return;
    }
    auto put = [pad](size_t offset, int16_t value) { std::memcpy(pad + offset, &value, sizeof(value)); };
    put(gta::kPadLeftStickX, c.stickX);
    put(gta::kPadLeftStickY, c.stickY);
    put(gta::kPadButtonSquare, c.square);
    put(gta::kPadButtonCross, c.cross);
    put(gta::kPadPedWalk, c.walk);
}

} // namespace cj
```

```cpp
static void True() { g_events.push_back("True"); }
static void X() { g_events.push_back("X"); True(); }
static void Ours() {
    CallHook::Scope scope(*g_hook);
    reinterpret_cast<void (*)()>(scope.Target())();
    if (scope.Outermost()) {
        g_events.push_back("tick");
    }
}
// A plugin that overwrote the call and kept calling the real function directly (what happened in the user's game).
static void W2() { g_events.push_back("W2"); True(); }
// Plugins that overwrote the call after our patch and saved OUR wrapper as their "original".
static void W() { g_events.push_back("W"); Ours(); }
static void W3() { g_events.push_back("W3"); Ours(); }

static void Poke(void (*fn)()) {
    g_site[0] = 0xE8;
    const int32_t rel = static_cast<int32_t>(reinterpret_cast<intptr_t>(fn) - reinterpret_cast<intptr_t>(g_site + 5));
    CHECK(static_cast<intptr_t>(rel) == reinterpret_cast<intptr_t>(fn) - reinterpret_cast<intptr_t>(g_site + 5)); // fits in rel32
    std::memcpy(g_site + 1, &rel, 4);
}

// What the game does: execute the call instruction.
static void GameCallsTheSite() {
    int32_t rel = 0;
    std::memcpy(&rel, g_site + 1, 4);
    const uintptr_t target = reinterpret_cast<uintptr_t>(g_site + 5) + static_cast<uintptr_t>(static_cast<intptr_t>(rel));
    reinterpret_cast<void (*)()>(target)();
}

static std::vector<std::string> Run() {
    g_events.clear();
    GameCallsTheSite();
    return g_events;
}

static void Fresh(CallHook& hook) {
    g_hook = &hook;
    g_logs.clear();
```

```cpp
#pragma once
#include <cstdint>
#include <cstdio>
#include <cstring>

namespace cj {

// Platform hooks. On Windows they make code writable and flush the instruction cache; native tests leave them null.
using MemProtectFn = bool (*)(void* addr, size_t size, bool writable);
inline MemProtectFn g_memProtect = nullptr;
using HookLogFn = void (*)(const char* line);
inline HookLogFn g_hookLog = nullptr;

// Redirects one `call rel32` to a replacement function. The replacement chains to what the call used to
// target. If another plugin later overwrites the call, Watch() re-hooks it and chains through the new
// target, keeping every plugin in the chain.
class CallHook {
public:
    static constexpr int kMaxRehooks = 5;

    CallHook(const char* name, uint8_t* site, void* replacement, uintptr_t trueFunction)
        : name_(name), site_(site), replacement_(replacement), trueFn_(trueFunction) {}

    // Returns false, patching nothing, when the site is not a call instruction.
    bool Install() {
        if (site_[0] != 0xE8) {
            Logf("%s: 0x%X is not a call (first byte %02X); hook not installed", name_, Addr(site_), site_[0]);
            return false;
        }
        chain_ = fallback_ = TargetOf(ReadRel());
        if (!Patch()) {
            return false;
        }
        installed_ = true;
        Logf("%s: hook installed at 0x%X (original target 0x%X)", name_, Addr(site_), Addr(chain_));
        return true;
    }

    // Poll this from a thread; cheap when nothing changed.
    void Watch() {
        if (!installed_) {
            return;
        }
        const int32_t rel = ReadRel();
        const uint8_t op = site_[0];
        if (op == 0xE8 && rel == patchedRel_) {
            pendingValid_ = false;
            return;
        }
        if (givenUp_) {
            return;
        }
        if (rehooks_ >= kMaxRehooks) {
            if (!reportedLimit_) {
                reportedLimit_ = true;
                Logf("%s: no more re-hooks (%d used); later changes are ignored", name_, rehooks_);
            }
            return;
        }
        // Another plugin may still be writing the operand: act only on two equal readings in a row.
        const uint64_t key = (static_cast<uint64_t>(op) << 32) | static_cast<uint32_t>(rel);
        if (!pendingValid_ || pendingKey_ != key) {
            pendingValid_ = true;
            pendingKey_ = key;
            return;
        }
        pendingValid_ = false;
        if (op != 0xE8) {
            givenUp_ = true;
            Logf("%s: call site was replaced by something that is not a call (bytes %02X %02X %02X %02X %02X); giving up",
                 name_, site_[0], site_[1], site_[2], site_[3], site_[4]);
            return;
        }
        ++rehooks_;
        fallback_ = chain_; // whoever we chained to before this plugin came in
        chain_ = TargetOf(rel);
        Logf("%s: another plugin changed the call, it now targets 0x%X; re-hooking and chaining through it (%d/%d)",
             name_, Addr(chain_), rehooks_, kMaxRehooks);
        Patch();
    }

    bool Called() const { return called_; }

    // Used inside the replacement function:
    //   CallHook::Scope scope(hook);
    //   call(scope.Target());
    //   if (scope.Outermost()) { ...our work... }
    class Scope {
    public:
        explicit Scope(CallHook& hook) : hook_(hook), depth_(hook.depth_++) {
            if (!hook.called_) {
                hook.called_ = true;
                hook.Logf("%s: first call from the game loop", hook.name_);
            }
        }
        ~Scope() { --hook_.depth_; }
        Scope(const Scope&) = delete;
        Scope& operator=(const Scope&) = delete;

        // What to call as "the original": the current chain at depth 0; the chain we had before the last re-hook when a
        // plugin chained back into us (depth 1); the real function if it chains back again (depth 2 or more).
        uintptr_t Target() const { return depth_ == 0 ? hook_.chain_ : depth_ == 1 ? hook_.fallback_ : hook_.trueFn_; }
        bool Outermost() const { return depth_ == 0; }

    private:
        CallHook& hook_;
        int depth_;
    };

private:
    static unsigned Addr(const void* p) { return static_cast<unsigned>(reinterpret_cast<uintptr_t>(p)); }
    static unsigned Addr(uintptr_t v) { return static_cast<unsigned>(v); }

    int32_t ReadRel() const {
        int32_t rel = 0;
        std::memcpy(&rel, site_ + 1, sizeof(rel));
        return rel;
    }
    uintptr_t TargetOf(int32_t rel) const {
        return reinterpret_cast<uintptr_t>(site_) + 5 + static_cast<uintptr_t>(static_cast<intptr_t>(rel));
    }

    bool Patch() {
        const intptr_t delta = reinterpret_cast<intptr_t>(replacement_) - static_cast<intptr_t>(reinterpret_cast<uintptr_t>(site_) + 5);
        const int32_t rel = static_cast<int32_t>(delta);
        if (g_memProtect && !g_memProtect(site_, 5, true)) {
            Logf("%s: could not make the call site writable", name_);
            return false;
        }
        patchedRel_ = rel;
        std::memcpy(site_ + 1, &rel, sizeof(rel)); // a single 4-byte store inside one cache line
        if (g_memProtect) {
            g_memProtect(site_, 5, false);
        }
        return true;
    }

    template <class... Args>
    void Logf(const char* fmt, Args... args) const {
        if (!g_hookLog) {
            return;
        }
        char line[256];
        std::snprintf(line, sizeof(line), fmt, args...);
        g_hookLog(line);
    }

    const char* name_;
    uint8_t* site_;
    void* replacement_;
    uintptr_t trueFn_;
    uintptr_t chain_ = 0;
    uintptr_t fallback_ = 0;
    int32_t patchedRel_ = 0;
    bool installed_ = false;
    bool called_ = false;
    int depth_ = 0;
    int rehooks_ = 0;
    bool givenUp_ = false;
    bool reportedLimit_ = false;
    bool pendingValid_ = false;
    uint64_t pendingKey_ = 0;
};

} // namespace cj
```

```cpp
// outside goes through BridgeIo, so it runs under native tests against fake ped and pad memory.

class BridgeIo {
public:
    virtual ~BridgeIo() = default;
    virtual uint8_t* Ped() = 0;      // the focused player ped, or nullptr before a game is loaded
    virtual uint8_t* Pad() = 0;      // CPad::Pads[0]

    virtual void SendEcho(const EchoPacket& echo) = 0;
    virtual void SendPose(const PosePacket& pose) = 0;
    // Fills the skeleton of the ped; false when it has none (not drawn yet, loading...).
    virtual bool ReadSkeleton(uint8_t* ped, Skeleton& out) = 0;

inline RwMat* PedMatrix(uint8_t* ped) {
    return *reinterpret_cast<RwMat**>(ped + gta::kMatrixPtr);
}

inline float* PedPosition(uint8_t* ped) {
    auto* matrix = *reinterpret_cast<uint8_t**>(ped + gta::kMatrixPtr);
    return reinterpret_cast<float*>(matrix ? matrix + gta::kMatrixPos : ped + gta::kPlacementPos);
}

inline bool PedInVehicle(uint8_t* ped) {
    return (*reinterpret_cast<uint32_t*>(ped + gta::kPedFlags) & gta::kPedFlagInVehicle) != 0;

class BridgeCore {
public:
    // Right after CPad::UpdatePads inside CGame::Process: give CJ the pad that matches the Minecraft player.
    void PrePad(BridgeIo& io) {
        if (!engaged_) {
            return;
        }
        uint8_t* ped = io.Ped();
        uint8_t* pad = io.Pad();
        if (!ped || !pad || PedInVehicle(ped)) {
            return;
        }
        ApplyPad(pad, driver_.Command());
    }

    // After CGame::Process.
    void Tick(BridgeIo& io) {
        uint8_t* ped = io.Ped();
        if (!ped) {
            if (!loggedNoPed_) {
                loggedNoPed_ = true;
                io.Log("no player ped yet; waiting");
            }
            DrainAndDiscard(io); // packets from before the game was loaded are stale
            return;
        }
        loggedNoPed_ = false;

        const uint32_t now = io.NowMs();
        float* pos = PedPosition(ped);
        // Where the game left CJ after animating him this frame.
        const Vec3 sampled{pos[0], pos[1], pos[2]};
        const bool inVehicle = PedInVehicle(ped);

        bool accepted = false;
        uint8_t buffer[256];
        for (;;) {
            const int n = io.Recv(buffer, sizeof(buffer));
            if (n < 0) {
                break;
            }
            if (inVehicle) {
                continue; // never drive a CJ who is inside a vehicle
            }
            StatePacket state;
            if (!ParseState(buffer, static_cast<size_t>(n), state)) {
                if (++rejected_ % 100 == 1) {
                    LogF(io, "rejected malformed datagram (%u so far, last size %d)", rejected_, n);
                }
                continue;
            }
            Vec3 unused;
            if (puppet_.Update(state, now, sampled, unused)) {
                driver_.OnState(state);
                lastAck_ = state.seq;
                accepted = true;
            }
        }

        if (inVehicle) {
            if (engaged_) {
                Release(io, "CJ got into a vehicle");
            }
            return;
        }
        if (engaged_ && !accepted && puppet_.Expired(now)) {
            LogF(io, "no state for %u ms: puppet released, densities restored", Puppet::kTimeoutMs);
            Release(io, nullptr);
            return;
        }
        if (accepted && !engaged_) {
            Engage(io, sampled, now);
        }
        if (!engaged_) {
            return;
        }

        MeasureAnimationSpeed(io, sampled, now);
        *io.PedDensity() = 0.0f; // scripts and cull zones may raise them again
        *io.CarDensity() = 0.0f;

        io.SendEcho(MakeEcho(lastAck_, now, sampled.x, sampled.y, sampled.z));
        Skeleton skeleton;
        RwMat* matrix = PedMatrix(ped);
        if (matrix && io.ReadSkeleton(ped, skeleton)) {
            PosePacket pose;
            if (BuildPose(pose, lastAck_, now, *matrix, skeleton)) {
                io.SendPose(pose);
            }
        }

        // Back to the stage. Z stays with the game's gravity, so CJ keeps standing on the ground.
        pos[0] = stage_.x;
        pos[1] = stage_.y;
    }

private:
    struct Stage {
        float x = 0.0f;
        float y = 0.0f;
    };

    template <class... Args>
    static void LogF(BridgeIo& io, const char* fmt, Args... args) {
        char line[192];
        std::snprintf(line, sizeof(line), fmt, args...);
        io.Log(line);
    }

    static void DrainAndDiscard(BridgeIo& io) {
        uint8_t buffer[256];
        while (io.Recv(buffer, sizeof(buffer)) >= 0) {
        }
    }

    void Engage(BridgeIo& io, Vec3 at, uint32_t now) {
        engaged_ = true;
        stage_ = {at.x, at.y};
        savedPedDensity_ = *io.PedDensity();
        savedCarDensity_ = *io.CarDensity();
        lastTickMs_ = now;
        driftSum_ = 0.0f;
        dtSumMs_ = 0;
        frames_ = 0;
        LogF(io, "puppet engaged: CJ stays at GTA (%.1f, %.1f), densities zeroed", at.x, at.y);
    }

    void Release(BridgeIo& io, const char* reason) {
        *io.PedDensity() = savedPedDensity_;
        *io.CarDensity() = savedCarDensity_;
        puppet_.Reset();
        driver_.Reset();
        engaged_ = false;
        if (reason) {
            LogF(io, "puppet released: %s", reason);
        }
    }

    // How far the game moved CJ since the last frame (before we put him back) is the speed of his animation.
    void MeasureAnimationSpeed(BridgeIo& io, Vec3 sampled, uint32_t now) {
        const float dx = sampled.x - stage_.x;
        const float dy = sampled.y - stage_.y;
        driftSum_ += std::sqrt(dx * dx + dy * dy);
        dtSumMs_ += now - lastTickMs_;
        lastTickMs_ = now;
        ++frames_;
        if (dtSumMs_ >= 2000) {
            LogF(io, "anim speed %.2f m/s over %u frames", driftSum_ / (static_cast<float>(dtSumMs_) / 1000.0f), frames_);
            driftSum_ = 0.0f;
            dtSumMs_ = 0;
            frames_ = 0;
        }
    }

    Puppet puppet_;
    PadDriver driver_;
    bool engaged_ = false;
    bool loggedNoPed_ = false;
    Stage stage_;
    float savedPedDensity_ = 1.0f;
    float savedCarDensity_ = 1.0f;
    uint32_t lastAck_ = 0;
    uint32_t rejected_ = 0;
    uint32_t lastTickMs_ = 0;
    uint32_t dtSumMs_ = 0;
    uint32_t frames_ = 0;
    float driftSum_ = 0.0f;
};

} // namespace cj
```

```cpp
#include <winsock2.h>
#include <windows.h>

#include <cstdint>

#include "bridge_core.h"
#include "log.h"
#include "ped_layout.h"

namespace cj::bridge {
namespace {

constexpr uint16_t kGtaPort = 34560;  // we listen here
constexpr uint16_t kEchoPort = 34561; // Minecraft (or the probe) listens here

SOCKET OpenSocket() {
    WSADATA wsa;
    if (WSAStartup(MAKEWORD(2, 2), &wsa) != 0) {
        Log("WSAStartup failed");
        return INVALID_SOCKET;
    }
    SOCKET s = socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    if (s == INVALID_SOCKET) {
        Log("socket() failed: %d", WSAGetLastError());
        return INVALID_SOCKET;
    }
    u_long nonBlocking = 1;
    ioctlsocket(s, FIONBIO, &nonBlocking);
    // Windows reports ICMP "port unreachable" from a previous sendto as a recv error; turn that off.
    BOOL noConnReset = FALSE;
    DWORD bytes = 0;
    WSAIoctl(s, 0x9800000C /* SIO_UDP_CONNRESET */, &noConnReset, sizeof(noConnReset), nullptr, 0, &bytes, nullptr, nullptr);

    sockaddr_in addr{};
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_LOOPBACK);
    addr.sin_port = htons(kGtaPort);
    if (bind(s, reinterpret_cast<sockaddr*>(&addr), sizeof(addr)) != 0) {
        Log("bind(127.0.0.1:%u) failed: %d", kGtaPort, WSAGetLastError());
        closesocket(s);
        return INVALID_SOCKET;
    }
    Log("listening on 127.0.0.1:%u, sending to 127.0.0.1:%u", kGtaPort, kEchoPort);
    return s;
}

uint8_t* FocusedPlayerPed() {
    const uint8_t focus = *reinterpret_cast<volatile uint8_t*>(gta::kPlayerInFocus);
    if (focus >= gta::kMaxPlayers) {
        return nullptr;
    }
    auto* info = reinterpret_cast<uint8_t*>(gta::kPlayersArray) + focus * gta::kPlayerInfoSize;
    return *reinterpret_cast<uint8_t**>(info); // CPlayerInfo::m_pPed is the first member; null before a game is loaded
}

// Winsock and the live game behind the BridgeIo interface that BridgeCore (and its tests) use.
class WinIo : public BridgeIo {
public:
    bool Open() {
        sock_ = OpenSocket();
        sendTo_.sin_family = AF_INET;
        sendTo_.sin_addr.s_addr = htonl(INADDR_LOOPBACK);
        sendTo_.sin_port = htons(kEchoPort);
        return sock_ != INVALID_SOCKET;
    }

    uint8_t* Ped() override { return FocusedPlayerPed(); }
    uint8_t* Pad() override { return reinterpret_cast<uint8_t*>(gta::kPadsArray); }
    float* PedDensity() override { return reinterpret_cast<float*>(gta::kPedDensityMultiplier); }
    float* CarDensity() override { return reinterpret_cast<float*>(gta::kCarDensityMultiplier); }
    uint32_t NowMs() override { return GetTickCount(); }

    int Recv(void* buf, size_t cap) override {
        for (;;) {
            const int n = recv(sock_, static_cast<char*>(buf), static_cast<int>(cap), 0);
            if (n != SOCKET_ERROR) {
                return n;
            }
            const int err = WSAGetLastError();
            if (err == WSAEMSGSIZE) {
                return static_cast<int>(cap) + 1; // oversized datagram: consumed, will be rejected by the parser
            }
            if (err == WSAECONNRESET) {
                continue; // stale ICMP error from an earlier sendto: skip it
            }
            return -1; // WSAEWOULDBLOCK: nothing left
        }
    }

    void SendEcho(const EchoPacket& echo) override { Send(&echo, sizeof(echo)); }
    void SendPose(const PosePacket& pose) override { Send(&pose, pose.Size()); }

    // RpHAnimHierarchy* GetAnimHierarchyFromSkinClump(RpClump*): numNodes, the world-space matrix array and the node ids.
    bool ReadSkeleton(uint8_t* ped, Skeleton& out) override {
        void* clump = *reinterpret_cast<void**>(ped + gta::kEntityClump);
        if (!clump) {
            return false;
        }
        using GetHierarchyFn = uint8_t*(__cdecl*)(void*);
        auto* hierarchy = reinterpret_cast<GetHierarchyFn>(gta::kGetAnimHierarchyFromSkinClump)(clump);
        if (!hierarchy) {
            return false;
        }
        const int32_t count = *reinterpret_cast<int32_t*>(hierarchy + gta::kHierNumNodes);
        const auto* matrices = *reinterpret_cast<const RwMat**>(hierarchy + gta::kHierMatrixArray);
        const uint8_t* nodeInfo = *reinterpret_cast<const uint8_t**>(hierarchy + gta::kHierNodeInfo);
        if (count <= 0 || count > static_cast<int32_t>(kMaxBones) || !matrices || !nodeInfo) {
            return false;
        }
        out.matrices = matrices;
        out.count = count;
        for (int32_t i = 0; i < count; i++) {
            out.ids[i] = *reinterpret_cast<const int32_t*>(nodeInfo + static_cast<size_t>(i) * gta::kNodeInfoStride);
        }
        return true;
    }

    void Log(const char* line) override { cj::Log("%s", line); }

private:
    void Send(const void* data, size_t size) {
        sendto(sock_, static_cast<const char*>(data), static_cast<int>(size), 0,
               reinterpret_cast<const sockaddr*>(&sendTo_), sizeof(sendTo_));
    }

    SOCKET sock_ = INVALID_SOCKET;
    sockaddr_in sendTo_{};
};

WinIo g_io;
BridgeCore g_core;
bool g_opened = false;
bool g_open = false;

bool EnsureOpen() {
    if (!g_opened) {
        g_opened = true;
        g_open = g_io.Open();
    }
    return g_open;
}

} // namespace

        g_core.Tick(g_io);
    }
}

void PrePad() {

    }
```

```cpp
// GTA sleeps inside its message loop (before CGame::Process runs) while ForegroundApp is 0,

        cj::Log("---- cj_bridge loaded ----");
        if (cj::InstallHooks()) {
            CreateThread(nullptr, 0, KeepAliveThread, nullptr, 0, nullptr);

    }
```

`tools/pose_probe.py`:

```python
#!/usr/bin/env python3
"""Stand-in for the Minecraft mod: plays scripted movement phases to the GTA bridge and checks the Pose packets."""
import math
import socket
import statistics
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent / "protocol"))
import cjproto as p  # noqa: E402

GTA_ADDR = ("127.0.0.1", 34560)
ECHO_ADDR = ("127.0.0.1", 34561)
RATE_HZ = 60.0
START = (100.0, 64.0, 100.0)

# name, seconds, horizontal speed in blocks/s, flags
PHASES = [
    ("idle", 4.0, 0.0, p.FLAG_ON_GROUND),
    ("walk", 5.0, 1.3, p.FLAG_ON_GROUND | p.FLAG_SNEAK),
    ("run", 5.0, 4.3, p.FLAG_ON_GROUND),
    ("sprint", 5.0, 5.6, p.FLAG_ON_GROUND | p.FLAG_SPRINT),
]


def drain(sock):
    packets = []
    while True:
        try:
            data, _ = sock.recvfrom(4096)
        except BlockingIOError:
            return packets
        packets.append(data)


def energy(poses):
    """Mean over every bone and axis of the standard deviation of its position during the phase."""
    by_id = [{b.node_id: b for b in po.bones} for po in poses]
    ids = set.intersection(*(set(d) for d in by_id))
    stds = []
    for node in ids:
        for axis in range(3):
            stds.append(statistics.pstdev([d[node].pos[axis] for d in by_id]))
    return statistics.fmean(stds) if stds else 0.0


def main():
    rx = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    rx.bind(ECHO_ADDR)
    rx.setblocking(False)
    tx = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)

    seq = 0
    pos = list(START)

    def send(speed, flags, vy=0.0):
        nonlocal seq
        state = p.State(seq=seq, ts_ms=int(time.monotonic() * 1000) & 0xFFFFFFFF, pos=tuple(pos),
                        vel=(speed, vy, 0.0), yaw=0.0, pitch=0.0, flags=flags)
        tx.sendto(p.pack_state(state), GTA_ADDR)
        seq += 1

    # Phase 0: let a previous session expire (1 s without state), or its stale packets would be mistaken for ours.
    quiet_since = time.monotonic()
    deadline = time.monotonic() + 6.0
    while time.monotonic() < deadline and time.monotonic() - quiet_since < 1.3:
        time.sleep(0.05)
        if drain(rx):
            quiet_since = time.monotonic()

    # Phase 1: handshake, until a Pose acknowledges one of our packets.
    handshake = set()
    engaged = False
    print("waiting for GTA to answer (load a game in GTA first; stand somewhere quiet) ...")
    deadline = time.monotonic() + 30.0
    while not engaged and time.monotonic() < deadline:
        handshake.add(seq)
        send(0.0, p.FLAG_ON_GROUND)
        time.sleep(0.05)
        for data in drain(rx):
            try:
                if p.unpack_pose(data).ack_seq in handshake:
                    engaged = True
            except ValueError:
                pass
    if not engaged:
        print("FAIL: no Pose from GTA within 30 s")
        return 2
    print("GTA answered with a Pose; running the phases (watch the GTA window)")

    # Phase 2: scripted movement.
    results = {}
    bad_quat = 0.0
    farthest = 0.0
    bone_sets = set()
    for name, seconds, speed, flags in PHASES:
        poses = []
        start = time.monotonic()
        next_send = start
        while time.monotonic() - start < seconds:
            pos[0] += speed / RATE_HZ
            send(speed, flags)
            for data in drain(rx):
                try:
                    pose = p.unpack_pose(data)
                except ValueError:
                    continue
                poses.append(pose)
                bone_sets.add(tuple(sorted(b.node_id for b in pose.bones)))
                for b in pose.bones:
                    bad_quat = max(bad_quat, abs(math.sqrt(sum(c * c for c in b.quat)) - 1.0))
                    farthest = max(farthest, math.sqrt(sum(c * c for c in b.pos)))
            next_send += 1.0 / RATE_HZ
            time.sleep(max(0.0, next_send - time.monotonic()))
        results[name] = poses

    # Informative: one jump (leaves the ground going up, then lands)
    start = time.monotonic()
    jump_poses = []
    next_send = start
    while time.monotonic() - start < 2.0:
        t = time.monotonic() - start
        airborne = 0.1 < t < 0.7
        send(0.0, 0 if airborne else p.FLAG_ON_GROUND, vy=8.0 if 0.1 < t < 0.2 else 0.0)
        for data in drain(rx):
            try:
                jump_poses.append(p.unpack_pose(data))
            except ValueError:
                pass
        next_send += 1.0 / RATE_HZ
        time.sleep(max(0.0, next_send - time.monotonic()))

    e = {name: energy(po) if len(po) > 2 else 0.0 for name, po in results.items()}
    print(f"{'phase':8} {'poses':>6} {'bones':>6} {'energy':>8}")
    for name, _, _, _ in PHASES:
        po = results[name]
        print(f"{name:8} {len(po):6d} {len(po[0].bones) if po else 0:6d} {e[name]:8.4f}")
    if len(jump_poses) > 2:
        print(f"{'jump':8} {len(jump_poses):6d} {len(jump_poses[0].bones):6d} {energy(jump_poses):8.4f}   (informative)")
    print(f"bone sets seen: {len(bone_sets)}; worst |quat|-1: {bad_quat:.5f}; farthest bone from root: {farthest:.2f} m")

    failures = []
    for name, _, _, _ in PHASES:
        if len(results[name]) < 40:
            failures.append(f"{name}: only {len(results[name])} poses")
    if len(bone_sets) != 1:
        failures.append(f"the set of bones changed ({len(bone_sets)} different sets)")
    elif not 20 <= len(next(iter(bone_sets))) <= 48:
        failures.append(f"unexpected bone count {len(next(iter(bone_sets)))}")
    if bad_quat > 0.01:
        failures.append(f"a quaternion is not unit length (off by {bad_quat:.4f})")
    if farthest > 3.0:
        failures.append(f"a bone is {farthest:.2f} m from the root: not in CJ's own frame")
    if not e["walk"] > 2 * e["idle"] + 0.002:
        failures.append("walk does not move the skeleton more than idle")
    if not e["run"] > 3 * e["idle"] + 0.004:
        failures.append("run does not move the skeleton more than idle")
    if not e["sprint"] >= 0.8 * e["run"]:
        failures.append("sprint moves the skeleton less than run")

    for f in failures:
        print("FAIL:", f)
    print("PASS" if not failures else "FAIL")
    return 0 if not failures else 1


if __name__ == "__main__":
    sys.exit(main())
```
