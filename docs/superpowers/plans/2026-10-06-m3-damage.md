# M3 — Daño a mobs y rotura de bloques a tiros: plan de implementación

> **Para quien ejecute el plan:** usar superpowers:subagent-driven-development (recomendado) o superpowers:executing-plans. Los pasos usan casillas (`- [ ]`) para llevar el seguimiento.

**Goal:** que los disparos de CJ (las seis armas de fuego de M2) hagan daño a los mobs y rompan bloques, resueltos por el servidor integrado de Minecraft.

**Architecture:** el cliente captura origen, dirección y arma de cada disparo y lo encola en el servidor integrado (`server.execute`); el servidor resuelve cada perdigón (dispersión, rayo contra bloques y entidades, daño o vida del bloque) y devuelve el resultado al cliente por una cola en memoria, que dibuja las partículas donde cae cada perdigón. La lógica numérica (dispersión, reparto de perdigones, vida y regeneración de bloques) es Java puro y se prueba con pruebas automáticas; lo que toca Minecraft se verifica en el juego.

**Tech Stack:** Java 21, Fabric 1.21.1 (yarn 1.21.1+build.3, Loom 1.17.21), JUnit 5, Gson (ya en el mod).

**Spec:** `docs/superpowers/specs/2026-10-06-m3-damage-design.md` (y `2026-10-05-cj-in-minecraft-design.md`, sección 6; `docs/m2-results.md`).

## Review Focus

1. **Un perdigón que no toca nada dentro del rango** (o cuyo impacto queda más allá del alcance): ni daño, ni bloque, ni rotura; el resultado es un fallo en el extremo del rayo. → Tarea 1 (`PelletRay.classify`).
2. **`weapons.json` con valores absurdos** (daño o alcance ≤ 0 o NaN, dispersión fuera de [0, 1], perdigones 0 o enormes, empuje negativo, constantes de bloques ≤ 0): se rechazan al cargar con un mensaje claro y el mod no arranca a medias. → Tarea 2.
3. **Un bloque que cambia mientras se agrieta** (lo sustituye otro de distinta dureza, o desaparece): la vida empieza de nuevo y nunca queda una grieta huérfana. → Tarea 1 (`BlockHealthModel`).
4. **Bedrock y bloques de dureza negativa**: inmunes siempre; el agua y la lava no se golpean. → Tarea 1 (inmunidad) y Tarea 3 (el rayo ignora fluidos).
5. **Un fallo al resolver un disparo** (jugador muerto o desconectado, mundo descargado, excepción inesperada): no tumba el servidor ni deja el resto del mod sin funcionar, y se registra una sola vez. → Tarea 3.

```java
    }

    @Test

        for (int i = 0; i < 5000; i++) {
            double[] p = Spread.perturb(d, 0.08, rng);
            assertEquals(1.0, Math.sqrt(dot(p, p)), 1e-9);
            assertTrue(angle(d, p) <= limit, "angle " + angle(d, p));
        }
    }

        Random rng = new Random(7);

            double a = angle(d, Spread.perturb(d, 0.08, rng));
```

```java
package dev.cjmc.combat;

import java.util.Random;

/** Spreads a shot: turns an aim direction into a direction inside a cone around it. Pure maths, no Minecraft. */
public final class Spread {
    private Spread() {}

    /**
     * @param dir the aim direction (any length but not zero)
     * @param spread the tangent of the cone's half angle (the `spread` of weapons.json); 0 = no spread
     * @return a unit vector, uniformly distributed over the disc of radius `spread` seen from one unit away along `dir`
     */
    public static double[] perturb(double[] dir, double spread, Random rng) {
        double len = Math.sqrt(dir[0] * dir[0] + dir[1] * dir[1] + dir[2] * dir[2]);
        if (!Double.isFinite(len) || len < 1e-9) {
            throw new IllegalArgumentException("the direction is not usable");
        }
        if (!(spread >= 0) || !Double.isFinite(spread)) {
            throw new IllegalArgumentException("the spread must be a finite number >= 0");
        }
        double dx = dir[0] / len;
        double dy = dir[1] / len;
        double dz = dir[2] / len;
        if (spread == 0) {
            return new double[] {dx, dy, dz};
        }
        // the axis least aligned with d gives a first perpendicular; the cross product gives the second
        double ax = Math.abs(dx);
        double ay = Math.abs(dy);
        double az = Math.abs(dz);
        double hx = 0, hy = 0, hz = 0;
        if (ax <= ay && ax <= az) {
            hx = 1;
        } else if (ay <= az) {
            hy = 1;
        } else {
            hz = 1;
        }
        double ux = dy * hz - dz * hy;
        double uy = dz * hx - dx * hz;
        double uz = dx * hy - dy * hx;
        double ul = Math.sqrt(ux * ux + uy * uy + uz * uz);
        ux /= ul;
        uy /= ul;
        uz /= ul;
        double vx = dy * uz - dz * uy;
        double vy = dz * ux - dx * uz;
        double vz = dx * uy - dy * ux;
        double r = spread * Math.sqrt(rng.nextDouble());
        double a = 2 * Math.PI * rng.nextDouble();
        double c = Math.cos(a) * r;
        double s = Math.sin(a) * r;
        double px = dx + ux * c + vx * s;
        double py = dy + uy * c + vy * s;
        double pz = dz + uz * c + vz * s;
        double pl = Math.sqrt(px * px + py * py + pz * pz);
        return new double[] {px / pl, py / pl, pz / pl};
    }
}
```

```java
package dev.cjmc.combat;

/** The numbers of a pellet's ray: how long it is, its random seed, and what it hits. Pure maths, no Minecraft. */
public final class PelletRay {
    /** The farthest a shot reaches, whatever a weapon's `range` says. */
    public static final double MAX_RANGE = 100.0;

    public enum Hit { MISS, BLOCK, ENTITY }

    private PelletRay() {}

    /** The ray length for a weapon range: between 1 and MAX_RANGE blocks (a broken range gives 1, not a crash). */
    public static double length(float range) {
        if (!(range >= 1f)) {
            return 1.0;
        }
        return Math.min(range, MAX_RANGE);
    }

    /** A seed for each pellet of a shot, derived from the shot's own seed (SplitMix64), so that every pellet spreads differently. */
    public static long seed(long base, int pellet) {
        long z = base + 0x9E3779B97F4A7C15L * (pellet + 1L);
        z = (z ^ (z >>> 30)) * 0xBF58476D1CE4E5B9L;
        z = (z ^ (z >>> 27)) * 0x94D049BB133111EBL;
        return z ^ (z >>> 31);
    }

    /**
     * What a pellet hits, given the distance to the first block and to the first entity along its ray (infinity when there is none).
     * The nearest wins and a tie goes to the block, so nothing is hit through a wall; anything beyond `length` is a miss.
     */
    public static Hit classify(double blockDistance, double entityDistance, double length) {
        double nearest = Math.min(blockDistance, entityDistance);
        if (!(nearest <= length)) {
            return Hit.MISS; // also NaN
        }
        return entityDistance < blockDistance ? Hit.ENTITY : Hit.BLOCK;
    }
}
```

```java
package dev.cjmc.combat;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.Iterator;
import java.util.List;
import java.util.Map;

/**
 * The health of the blocks that are being shot, for one world. A block has health = max(hardness, minHardness) * healthPerHardness;
 * each hit takes `power` off it, and a block left alone for regenDelayTicks heals regenPerTick per tick. Positions are
 * BlockPos.asLong() values. Pure bookkeeping, no Minecraft: the caller reads the hardness and shows the cracks.
 */
public final class BlockHealthModel {
    public record Rules(double healthPerHardness, double minHardness, long regenDelayTicks, double regenPerTick) {}

    /** immune: the block cannot be broken by shots; broken: this hit finished it; stage: the cracks to show, 0..9 (-1: none). */
    public record Hit(boolean immune, boolean broken, int stage) {}

    /** The cracks of a position changed (stage -1: they are gone and the block is forgotten). */
    public record Change(long pos, int stage) {}

    private static final double EPS = 1e-9;

    private static final class Entry {
        double hardness;
        double max;
        double health;
        long lastHit;
        int reportedStage;
    }

    private final Rules rules;
    private final Map<Long, Entry> entries = new HashMap<>();

    public BlockHealthModel(Rules rules) {
        this.rules = rules;
    }

    public Hit hit(long pos, double hardness, double power, long tick) {
        if (!(hardness >= 0) || !Double.isFinite(hardness)) {
            return new Hit(true, false, -1); // bedrock and the like (negative hardness), or nonsense
        }
        Entry e = entries.get(pos);
        if (e != null && Math.abs(e.hardness - hardness) > 1e-6) {
            entries.remove(pos); // another block now: it does not inherit the damage
            e = null;
        }
        if (!(power > 0) || !Double.isFinite(power)) {
            return new Hit(false, false, e == null ? -1 : e.reportedStage);
        }
        if (e == null) {
            e = new Entry();
            e.hardness = hardness;
            e.max = Math.max(hardness, rules.minHardness()) * rules.healthPerHardness();
            e.health = e.max;
            e.reportedStage = -1;
            entries.put(pos, e);
        }
        e.health -= power;
        e.lastHit = tick;
        if (e.health <= EPS) {
            entries.remove(pos);
            return new Hit(false, true, -1);
        }
        e.reportedStage = stage(e);
        return new Hit(false, false, e.reportedStage);
    }

    /** Heals the blocks that have been left alone long enough; returns the positions whose cracks changed. */
    public List<Change> tick(long now) {
        List<Change> changes = new ArrayList<>();
        if (rules.regenPerTick() <= 0) {
            return changes;
        }
        Iterator<Map.Entry<Long, Entry>> it = entries.entrySet().iterator();
        while (it.hasNext()) {
            Map.Entry<Long, Entry> en = it.next();
            Entry e = en.getValue();
            if (now - e.lastHit <= rules.regenDelayTicks()) {
                continue;
            }
            e.health = Math.min(e.max, e.health + rules.regenPerTick());
            if (e.health >= e.max - EPS) {
                it.remove();
                changes.add(new Change(en.getKey(), -1));
                continue;
            }
            int s = stage(e);
            if (s != e.reportedStage) {
                e.reportedStage = s;
                changes.add(new Change(en.getKey(), s));
            }
        }
        return changes;
    }

    public void clear() {
        entries.clear();
    }

    public int tracked() {
        return entries.size();
    }

    private static int stage(Entry e) {
        int s = (int) Math.floor((1.0 - e.health / e.max) * 10.0);
        return Math.max(0, Math.min(9, s));
    }
}
```

```java
package dev.cjmc.combat;

import dev.cjmc.combat.BlockHealthModel.Change;
import java.util.HashMap;
import java.util.Map;
import net.minecraft.registry.RegistryKey;
import net.minecraft.server.world.ServerWorld;
import net.minecraft.util.math.BlockPos;
import net.minecraft.world.World;

/** One BlockHealthModel per world, healed by the server tick; it also puts the cracks on the blocks. */
public final class BlockHealthTracker {
    /** The id every crack is shown under (the game keeps one crack per id and position). */
    public static final int CRACKS_ID = 0x4A4D43;

    private final BlockHealthModel.Rules rules;
    private final Map<RegistryKey<World>, BlockHealthModel> models = new HashMap<>();

    public BlockHealthTracker(BlockHealthModel.Rules rules) {
        this.rules = rules;
    }

    public BlockHealthModel of(ServerWorld world) {
        return models.computeIfAbsent(world.getRegistryKey(), key -> new BlockHealthModel(rules));
    }

    /** Server tick of one world: heal the blocks left alone and update their cracks. */
    public void tick(ServerWorld world) {
        BlockHealthModel model = models.get(world.getRegistryKey());
        if (model == null) {
            return;
        }
        for (Change change : model.tick(world.getTime())) {
            world.setBlockBreakingInfo(CRACKS_ID, BlockPos.fromLong(change.pos()), change.stage());
        }
    }

    /** The world was unloaded: its blocks are forgotten. */
    public void forget(ServerWorld world) {
        models.remove(world.getRegistryKey());
    }
}
```

```java
import net.minecraft.entity.Entity;
import net.minecraft.entity.LivingEntity;
import net.minecraft.entity.projectile.ProjectileUtil;
import net.minecraft.server.MinecraftServer;
import net.minecraft.server.network.ServerPlayerEntity;
import net.minecraft.server.world.ServerWorld;
import net.minecraft.util.hit.BlockHitResult;
import net.minecraft.util.hit.EntityHitResult;
import net.minecraft.util.hit.HitResult;
import net.minecraft.util.math.BlockPos;
import net.minecraft.util.math.Box;
import net.minecraft.util.math.Vec3d;
import net.minecraft.world.RaycastContext;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

/** Resolves a shot on the server thread: damages what the pellets hit, wears down the blocks, and reports where each pellet ended. */
public final class ShotResolver {
    private static final Logger LOG = LoggerFactory.getLogger("cj_fabric");
    private static boolean failureLogged;

    private ShotResolver() {}

    /** Called through server.execute: never throws, a failure is logged once and the shot is lost. */
    public static void resolve(MinecraftServer server, ShotRequest request) {
        try {
            resolveUnchecked(server, request);
        } catch (RuntimeException e) {
            if (!failureLogged) {
                failureLogged = true;
                LOG.error("a shot could not be resolved (further failures are not logged)", e);
            }
        }
    }

    private static void resolveUnchecked(MinecraftServer server, ShotRequest request) {
        WeaponCatalog catalog = CjCombat.catalog();
        BlockHealthTracker tracker = CjCombat.tracker();
        ServerPlayerEntity player = server.getPlayerManager().getPlayer(request.player());
        if (catalog == null || tracker == null || player == null || !player.isAlive() || player.isSpectator()) {
            return;
        }
        WeaponCatalog.WeaponDef def = catalog.byId(request.weaponId());
        if (def == null) {
            return;
        }
        ServerWorld world = player.getServerWorld();
        double length = PelletRay.length(def.range());
        List<ShotOutcome.Pellet> pellets = new ArrayList<>();
        for (int i = 0; i < def.pellets(); i++) {
            double[] dir = Spread.perturb(request.direction(), def.spread(), new Random(PelletRay.seed(request.seed(), i)));
            pellets.add(firePellet(world, player, def, catalog.blocks(), tracker, request.origin(), dir, length));
        }
        CjCombat.OUTCOMES.add(new ShotOutcome(request.origin(), pellets));
    }

    private static ShotOutcome.Pellet firePellet(ServerWorld world, ServerPlayerEntity player, WeaponCatalog.WeaponDef def,
                                                 WeaponCatalog.BlockRules rules, BlockHealthTracker tracker, double[] origin,
                                                 double[] dir, double length) {
        Vec3d from = new Vec3d(origin[0], origin[1], origin[2]);
        Vec3d to = from.add(dir[0] * length, dir[1] * length, dir[2] * length);

        BlockHitResult block = world.raycast(new RaycastContext(from, to, RaycastContext.ShapeType.OUTLINE,
                RaycastContext.FluidHandling.NONE, player));
        double blockDistance = block.getType() == HitResult.Type.MISS ? Double.POSITIVE_INFINITY : block.getPos().distanceTo(from);
        EntityHitResult entity = ProjectileUtil.raycast(player, from, to, new Box(from, to).expand(1.0),
                e -> !e.isSpectator() && e.canHit() && e != player, length * length);
        double entityDistance = entity == null ? Double.POSITIVE_INFINITY : entity.getPos().distanceTo(from);

        PelletRay.Hit hit = PelletRay.classify(blockDistance, entityDistance, length);
        switch (hit) {
            case ENTITY -> {
                hitEntity(world, player, def, entity.getEntity(), dir);
                Vec3d at = entity.getPos();
                return new ShotOutcome.Pellet(hit, at.x, at.y, at.z, 0, 0, 0);
            }
            case BLOCK -> {
                BlockPos pos = block.getBlockPos();
                hitBlock(world, player, def, rules, tracker, pos);
                Vec3d at = block.getPos();
                return new ShotOutcome.Pellet(hit, at.x, at.y, at.z, pos.getX(), pos.getY(), pos.getZ());
            }
            default -> {
                return new ShotOutcome.Pellet(hit, to.x, to.y, to.z, 0, 0, 0);
            }
        }
    }

    private static void hitEntity(ServerWorld world, ServerPlayerEntity player, WeaponCatalog.WeaponDef def, Entity target, double[] dir) {
        target.timeUntilRegen = 0; // every pellet and every round of a burst counts: the game would ignore damage within 10 ticks of the last
        target.damage(world.getDamageSources().playerAttack(player), def.damage());
        if (target instanceof LivingEntity living && def.knockback() > 0f) {
            double horizontal = Math.sqrt(dir[0] * dir[0] + dir[2] * dir[2]);
            if (horizontal > 1e-6) {
                living.takeKnockback(def.knockback(), -dir[0] / horizontal, -dir[2] / horizontal); // (x, z) point at the attacker
            }
        }
    }

    private static void hitBlock(ServerWorld world, ServerPlayerEntity player, WeaponCatalog.WeaponDef def,
                                 WeaponCatalog.BlockRules rules, BlockHealthTracker tracker, BlockPos pos) {
        BlockState state = world.getBlockState(pos);
        BlockHealthModel.Hit result = tracker.of(world).hit(pos.asLong(), state.getHardness(world, pos), def.blockPower(), world.getTime());
        if (result.immune()) {
            return;
        }
        if (result.broken()) {
            world.setBlockBreakingInfo(BlockHealthTracker.CRACKS_ID, pos, -1);
            BlockBreaker.breakBlock(world, pos, state, player, rules.dropsWithoutTool());
        } else {
            world.setBlockBreakingInfo(BlockHealthTracker.CRACKS_ID, pos, result.stage());
        }
    }
}
```

```java
package dev.cjmc;

import dev.cjmc.combat.CjCombat;
import dev.cjmc.combat.PelletRay;
import dev.cjmc.combat.ShotOutcome;
import dev.cjmc.combat.ShotRequest;
import dev.cjmc.combat.ShotResolver;
import java.util.concurrent.ConcurrentLinkedQueue;
import java.util.concurrent.ThreadLocalRandom;
import net.minecraft.block.BlockState;
import net.minecraft.client.MinecraftClient;
import net.minecraft.client.network.ClientPlayerEntity;
import net.minecraft.client.world.ClientWorld;
import net.minecraft.particle.BlockStateParticleEffect;
import net.minecraft.particle.ParticleTypes;
import net.minecraft.server.integrated.IntegratedServer;
import net.minecraft.util.math.BlockPos;
import net.minecraft.util.math.Vec3d;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

/**
 * Turns the shot events of GTA into shots in the world. The network thread queues the rounds; the client tick hands each one to
 * the integrated server (origin and direction of the player's eyes, the weapon), which damages mobs and wears down blocks
 * (dev.cjmc.combat), and draws what the server reports: a tracer and an impact for every pellet.
 */
public final class ShotEffects {
    public static final ShotEffects INSTANCE = new ShotEffects();
    private static final Logger LOG = LoggerFactory.getLogger("cj_fabric");
    private static final int MAX_ROUNDS_PER_TICK = 8;
    private static final int MAX_OUTCOMES_PER_TICK = 64;

    private final ShotDedup dedup = new ShotDedup();
    private final ConcurrentLinkedQueue<Integer> pending = new ConcurrentLinkedQueue<>(); // the GTA weapon id of each round
    private boolean warnedNoServer;

    private ShotEffects() {}

    /** Called from the network thread. */
    public void onShot(Protocol.Shot shot) {
        int rounds = dedup.newRounds(shot.shotSeq(), shot.rounds());
        for (int i = 0; i < rounds && pending.size() < 64; i++) {
            pending.add(shot.weapon());
        }
    }

    /** Called from the client thread every tick. */
    public void tick(MinecraftClient client) {
        ClientPlayerEntity player = client.player;
        ClientWorld world = client.world;
        if (player == null || world == null) {
            pending.clear();
            CjCombat.OUTCOMES.clear();
            return;
        }
        Integer weapon;
        for (int i = 0; i < MAX_ROUNDS_PER_TICK && (weapon = pending.poll()) != null; i++) {
            submit(client, player, weapon);
        }
        ShotOutcome outcome;
        for (int i = 0; i < MAX_OUTCOMES_PER_TICK && (outcome = CjCombat.OUTCOMES.poll()) != null; i++) {
            draw(world, outcome);
        }
    }

    private void submit(MinecraftClient client, ClientPlayerEntity player, int gtaWeapon) {
        IntegratedServer server = client.getServer();
        if (server == null) {
            if (!warnedNoServer) {
                warnedNoServer = true;
                LOG.warn("shots need the integrated server (single player); nothing is damaged on this connection");
            }
            return;
        }
        WeaponCatalog catalog = CjCombat.catalog();
        WeaponCatalog.WeaponDef def = catalog == null ? null : catalog.byGta(gtaWeapon);
        if (def == null) {
            return;
        }
        Vec3d eye = player.getCameraPosVec(1.0f);
        Vec3d look = player.getRotationVec(1.0f);
        ShotRequest request = new ShotRequest(player.getUuid(), new double[] {eye.x, eye.y, eye.z},
                new double[] {look.x, look.y, look.z}, def.id(), ThreadLocalRandom.current().nextLong());
        server.execute(() -> ShotResolver.resolve(server, request));
    }

    private void draw(ClientWorld world, ShotOutcome outcome) {
        double[] o = outcome.origin();
        boolean volley = outcome.pellets().size() > 1;
        for (ShotOutcome.Pellet p : outcome.pellets()) {
            Vec3d end = new Vec3d(p.x(), p.y(), p.z());
            Vec3d start = new Vec3d(o[0], o[1] - 0.25, o[2]);
            Vec3d along = end.subtract(start);
            if (along.length() > 1.0) { // the muzzle sits a little ahead of the eyes
                Vec3d muzzle = start.add(along.normalize().multiply(0.6));
                Vec3d rest = end.subtract(muzzle);
                double[][] points = ShotGeometry.tracerPoints(new double[] {muzzle.x, muzzle.y, muzzle.z},
                        new double[] {rest.x, rest.y, rest.z}, rest.length(), volley ? 4 : 12);
                for (double[] point : points) {
                    world.addParticle(ParticleTypes.END_ROD, point[0], point[1], point[2], 0, 0, 0);
                }
            }
            if (p.kind() == PelletRay.Hit.ENTITY) {
                for (int i = 0; i < (volley ? 2 : 6); i++) {
                    world.addParticle(ParticleTypes.CRIT, end.x, end.y, end.z, spread(world), world.random.nextDouble() * 0.3, spread(world));
                }
            } else if (p.kind() == PelletRay.Hit.BLOCK) {
                BlockState state = world.getBlockState(new BlockPos(p.blockX(), p.blockY(), p.blockZ()));
                if (!state.isAir()) { // the pellet may have just broken it
                    for (int i = 0; i < (volley ? 2 : 8); i++) {
                        world.addParticle(new BlockStateParticleEffect(ParticleTypes.BLOCK, state), end.x, end.y, end.z,
                                spread(world), world.random.nextDouble() * 0.3, spread(world));
                    }
                }
            }
        }
    }

    private static double spread(ClientWorld world) {
        return (world.random.nextDouble() - 0.5) * 0.4;
    }
}
```
