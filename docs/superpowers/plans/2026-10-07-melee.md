# Cuerpo a cuerpo (puño y bate): plan de implementación

> **Para agentes:** SUB-HABILIDAD OBLIGATORIA: usar superpowers:executing-plans (el usuario elige siempre la ejecución nativa) o superpowers:subagent-driven-development para ejecutar este plan tarea a tarea. Los pasos usan casillas (`- [ ]`).

**Objetivo:** que CJ pelee con el puño (mano vacía) y con el bate de béisbol: el golpe de GTA (animación, combos, sonido) provoca un ataque real en Minecraft contra mobs, con daño y empuje por las reglas del servidor. Un mob de 20 de vida cae en 6 golpes de puño o 4 de bate.

**Arquitectura:** el catálogo gana `reach`, `coneHalfAngle` e `item` y dos entradas (`fists`, `baseball_bat`). El cliente manda `INTENT_MELEE` (ya reservado en el protocolo v2) con el clic izquierdo; el puente lo traduce en el botón de ataque del mando simulado (sin apuntar) y gira a CJ hacia la mirada. El puente detecta cada golpe de la tarea de pelea de GTA (`CTaskSimpleFight`) y manda un `Shot` (sin protocolo nuevo) con `weapon` 0 (puño) o 5 (bate) y `rounds` = golpes; el cliente lo entrega al servidor, que elige el objetivo con una lógica pura (`MeleeTarget`) y le aplica el daño y el empuje como en M3. Un mixin anula el ataque vanilla contra entidades con la mano vacía o el bate.

**Tecnologías:** Java 21 / Fabric 1.21.1 con Yarn (JUnit 5), C++ del puente (pruebas nativas), Python 3 (conversor), GTA SA 1.0 US bajo Wine.

**Spec:** `docs/superpowers/specs/2026-10-07-melee-design.md`. Contexto: `docs/m3-results.md`, `docs/minigun-results.md`, `docs/rocket-launcher-results.md`.

## Global Constraints

- Protocolo v2 **sin cambios**: los golpes viajan como `Shot` con `weapon` 0 (puño) o 5 (bate) y `rounds` = golpes nuevos; el contador `shotSeq` es el acumulado compartido con las armas de fuego (`ShotCounter::Total`, que nunca retrocede). (Decisión del plan: la spec dejaba abierto un mensaje `Hit` nuevo o reutilizar `Shot`; se reutiliza `Shot` porque ya trae contador acumulado, envío doble y deduplicación en `ShotDedup`.)
- El paquete `dev.cjmc.combat` no usa clases de cliente.
- Toda arma con modelo tiene hueco (`WeaponSlot`, invariante nativa): el bate es el arma **5** de GTA, modelo **336** (a confirmar en vivo en la Tarea 3), hueco **1** (cuerpo a cuerpo). El puño es `weapon 0` (desarmado): sin modelo, sin hueco, sin ítem.
- Modelo del bate en `gta3.img`: `bat.dff`/`bat.txd` (un marco, una textura `alum_bat`), 91 vértices y 128 triángulos, 0,89 m de largo: lo admite el conversor sin cambios; solo se añade `"bat"` a `WEAPON_MODELS`.
- Catálogo: cada arma gana `reach` (alcance del golpe en bloques; 0 = no es cuerpo a cuerpo), `coneHalfAngle` (grados) e `item` (verdadero = tiene ítem). Validación: `reach` en [0, 10]; con `reach > 0`: `coneHalfAngle` en (0, 90], `damage > 0`, `explosionPower` 0 y `projectileSpeed` 0; con `reach` 0, `coneHalfAngle` 0. `gta` ahora puede ser 0 (el puño); sigue siendo único y ≤ 65535. `fists` es la única con `item: false`.
- Números (criterio del usuario: un mob de 20 de vida cae en 6 golpes de puño o 4 de bate): `fists` `damage` 3.4 (5 golpes = 17 no bastan, 6 = 20.4 sí), `reach` 3, `coneHalfAngle` 35, `knockback` 0.3; `baseball_bat` `damage` 6 (3 golpes = 18 no bastan, 4 = 24 sí), `reach` 3.2, `coneHalfAngle` 45, `knockback` 0.8. Movimiento y salto por defecto libres (`moveWhileFiring` true, `canJump` true) hasta medir GTA.

1. **Golpe contado dos veces o perdido:** un golpe de GTA es exactamente un `rounds` en el cliente; los combos no se cuentan doble y un golpe no se pierde al soltar el botón a media animación. → Tarea 4.

### Tarea 2: Elegir el objetivo del golpe (lógica pura)

**Archivos:**
- Crear: `cj-fabric/src/main/java/dev/cjmc/combat/MeleeTarget.java`
- Crear: `cj-fabric/src/test/java/dev/cjmc/combat/MeleeTargetTest.java`

**Interfaces:**
- Consume: nada de Minecraft.
- Produce: `MeleeTarget.pick(double[] eye, double[] look, double reach, double coneHalfAngleDegrees, double[][] centers, double[] radii) -> int` (índice del mejor objetivo, o −1). Un candidato es una esfera (centro y radio). Entra si la distancia del ojo a su superficie (`|centro − ojo| − radio`) es ≤ `reach` y está delante (el centro dentro del semiespacio de la mirada) y el ángulo entre la mirada y la dirección a su centro, restando el que subtiende su radio (`asin(min(1, radio / distancia))`), es ≤ `coneHalfAngleDegrees`. Gana el menor ángulo efectivo; el desempate, el más cercano (menor distancia). Una mirada o unos números no finitos o nulos dan −1.

```java
package dev.cjmc.combat;

import static org.junit.jupiter.api.Assertions.assertEquals;

import org.junit.jupiter.api.Test;

class MeleeTargetTest {
    private static final double[] EYE = {0, 0, 0};
    private static final double[] LOOK = {0, 0, 1}; // looking along +z

    private static int pick(double reach, double cone, double[][] centers, double[] radii) {
        return MeleeTarget.pick(EYE, LOOK, reach, cone, centers, radii);
    }

    @Test
    void aMobStraightAheadWithinReachIsPicked() {
        assertEquals(0, pick(3.0, 35.0, new double[][] {{0, 0, 2.0}}, new double[] {0.4}));
    }

    @Test
    void nothingGivesMinusOne() {
        assertEquals(-1, pick(3.0, 35.0, new double[][] {}, new double[] {}));
    }

    @Test
    void aMobBeyondReachIsNotPickedButItsNearSurfaceCounts() {
        assertEquals(-1, pick(3.0, 35.0, new double[][] {{0, 0, 3.6}}, new double[] {0.4})); // surface at 3.2 > 3.0
        assertEquals(0, pick(3.0, 35.0, new double[][] {{0, 0, 3.3}}, new double[] {0.4}));  // surface at 2.9 <= 3.0
    }

    @Test
    void aMobBehindTheMouseIsNeverPicked() {
        assertEquals(-1, pick(3.0, 90.0, new double[][] {{0, 0, -1.0}}, new double[] {0.4}));
    }

    @Test
    void aMobOutsideTheConeIsNotPickedButABigOneAtTheEdgeIs() {
        // 50 degrees off the look direction, 2 blocks away
        double a = Math.toRadians(50);
        double[][] c = {{2.0 * Math.sin(a), 0, 2.0 * Math.cos(a)}};
        assertEquals(-1, pick(3.0, 35.0, c, new double[] {0.1}));
        assertEquals(0, pick(3.0, 35.0, c, new double[] {1.0})); // it subtends asin(1/2) = 30 degrees: effective angle 20

        assertEquals(1, pick(3.0, 60.0, new double[][] {c[0], c[1]}, new double[] {r[0], r[1]})); // the more central one
        // the same angle at two distances: the nearer
        double[][] same = {{0, 0, 2.5}, {0, 0, 1.5}};
        assertEquals(1, pick(3.0, 35.0, same, new double[] {0.4, 0.4}));
```

```java
package dev.cjmc.combat;

/** Picks what a melee blow hits: the candidate (a sphere) closest to where the player looks, inside the weapon's reach and cone. */
public final class MeleeTarget {
    private MeleeTarget() {}

    /**
     * @return the index of the best candidate, or -1. A candidate counts when its surface is within `reach` of the eye, it is not behind
     *         the look direction and the angle between the look direction and its centre, less the angle its radius covers, is within
     *         the cone. The smallest such angle wins; a tie goes to the nearer one.
     */
    public static int pick(double[] eye, double[] look, double reach, double coneHalfAngleDegrees, double[][] centers, double[] radii) {
        double ll = Math.sqrt(look[0] * look[0] + look[1] * look[1] + look[2] * look[2]);
        if (!(ll > 1e-9) || !Double.isFinite(ll) || !(reach > 0) || !Double.isFinite(reach) || !(coneHalfAngleDegrees > 0)
                || !Double.isFinite(coneHalfAngleDegrees) || radii.length < centers.length) {
            return -1;
        }
        double cone = Math.toRadians(coneHalfAngleDegrees);
        int best = -1;
        double bestAngle = Double.POSITIVE_INFINITY;
        double bestDistance = Double.POSITIVE_INFINITY;
        for (int i = 0; i < centers.length; i++) {
            double dx = centers[i][0] - eye[0];
            double dy = centers[i][1] - eye[1];
            double dz = centers[i][2] - eye[2];
            double distance = Math.sqrt(dx * dx + dy * dy + dz * dz);
            double radius = radii[i];
            if (!Double.isFinite(distance) || !(radius >= 0) || !Double.isFinite(radius) || distance - radius > reach) {
                continue;
            }
            double angle = 0.0; // a centre at the eye is as good as dead centre
            if (distance > 1e-9) {
                double cos = (dx * look[0] + dy * look[1] + dz * look[2]) / (distance * ll);
                if (cos < 0.0) {
                    continue; // behind the player
                }
                angle = Math.acos(Math.min(1.0, cos));
                angle = Math.max(0.0, angle - Math.asin(Math.min(1.0, radius / distance)));
            }
            if (angle > cone) {
                continue;
            }
            if (angle < bestAngle - 1e-9 || (Math.abs(angle - bestAngle) <= 1e-9 && distance < bestDistance)) {
                best = i;
                bestAngle = angle;
                bestDistance = distance;
            }
        }
        return best;
    }
}
```

```python
#!/usr/bin/env python3
"""Stand-in for the Minecraft mod: holds INTENT_MELEE (the left mouse button) with fists (weapon 0) or the bat (weapon 5), then lets go,
and reports the blows GTA counted as Shot packets. Usage: melee_probe.py [weapon id, default 0] [cycles, default 2].
GTA must be running with a game loaded and nothing else talking to the bridge (close Minecraft)."""
import socket
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent / "protocol"))
import cjproto as p  # noqa: E402

GTA_ADDR = ("127.0.0.1", 34560)
ECHO_ADDR = ("127.0.0.1", 34561)
RATE_HZ = 60.0


def main(argv):
    weapon = int(argv[1]) if len(argv) > 1 else 0
    cycles = int(argv[2]) if len(argv) > 2 else 2
    rx = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    rx.bind(ECHO_ADDR)
    rx.setblocking(False)
    tx = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    seq = 0
    held = 0
    shots = {}  # shot_seq -> (gta_time_ms, rounds, weapon): each event arrives twice

    def send(intents):
        nonlocal seq
        state = p.State(seq=seq, ts_ms=int(time.monotonic() * 1000) & 0xFFFFFFFF, pos=(100.0, 64.0, 100.0), vel=(0.0, 0.0, 0.0),
                        yaw=0.0, pitch=0.0, flags=p.FLAG_ON_GROUND, intents=intents, weapon=weapon)
        tx.sendto(p.pack_state(state), GTA_ADDR)
        seq += 1

    def drain():
        nonlocal held
        while True:
            try:
                data, _ = rx.recvfrom(4096)
            except BlockingIOError:
                return
            try:
                shot = p.unpack_shot(data)
                shots[shot.shot_seq] = (shot.gta_time_ms, shot.rounds, shot.weapon)
                continue
            except ValueError:
                pass
            try:
                held = p.unpack_echo(data).weapon_held
            except ValueError:
                pass

    def hold(intents, seconds):
        start = time.monotonic()
        next_send = start
        while time.monotonic() - start < seconds:
            send(intents)
            drain()
            next_send += 1.0 / RATE_HZ
            time.sleep(max(0.0, next_send - time.monotonic()))

    hold(0, 3.0)  # equip
    for cycle in range(cycles):
        before = len(shots)
        print(f"cycle {cycle + 1}: striking for 8 s (watch the GTA window), then letting go for 3 s")
        hold(p.INTENT_MELEE, 8.0)
        hold(0, 3.0)
        blows = sum(r for _, r, _ in list(shots.values())[before:])
        print(f"  blows reported by the bridge: {blows}")
    print("weapon held according to GTA:", held)
    total = sum(r for _, r, _ in shots.values())
    weapons = sorted({w for _, _, w in shots.values()})
    print(f"{len(shots)} shot events, {total} blows in all; weapon ids in the events: {weapons}")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```

```java
package dev.cjmc.combat;

import dev.cjmc.WeaponCatalog;
import java.util.ArrayList;
import java.util.List;
import net.minecraft.entity.Entity;
import net.minecraft.entity.LivingEntity;
import net.minecraft.server.network.ServerPlayerEntity;
import net.minecraft.server.world.ServerWorld;
import net.minecraft.util.hit.BlockHitResult;
import net.minecraft.util.hit.HitResult;
import net.minecraft.util.math.Box;
import net.minecraft.util.math.Vec3d;
import net.minecraft.world.RaycastContext;

/** Resolves one melee blow on the server thread: the living entity nearest to where the player looks, in reach and cone, takes the hit. */
final class MeleeResolver {
    private MeleeResolver() {}

    static void strike(ServerWorld world, ServerPlayerEntity player, WeaponCatalog.WeaponDef def, ShotRequest request) {
        double[] eye = request.origin();
        double[] look = request.direction();
        Vec3d from = new Vec3d(eye[0], eye[1], eye[2]);
        Box area = new Box(from, from).expand(def.reach() + 2.0);
        List<LivingEntity> candidates = new ArrayList<>();
        for (Entity e : world.getOtherEntities(player, area, x -> x instanceof LivingEntity && x.isAlive() && !x.isSpectator() && x.canHit())) {
            candidates.add((LivingEntity) e);
        }
        double[][] centers = new double[candidates.size()][];
        double[] radii = new double[candidates.size()];
        for (int i = 0; i < centers.length; i++) {
            Box box = candidates.get(i).getBoundingBox();
            Vec3d c = box.getCenter();
            centers[i] = new double[] {c.x, c.y, c.z};
            radii[i] = 0.5 * Math.max(box.getLengthX(), Math.max(box.getLengthY(), box.getLengthZ()));
        }
        // a wall between the eye and the target stops the blow: take the nearest to the look direction among those in the open
        List<LivingEntity> open = new ArrayList<>();
        List<double[]> openCenters = new ArrayList<>();
        List<Double> openRadii = new ArrayList<>();
        for (int i = 0; i < centers.length; i++) {
            Vec3d to = new Vec3d(centers[i][0], centers[i][1], centers[i][2]);
            BlockHitResult wall = world.raycast(new RaycastContext(from, to, RaycastContext.ShapeType.COLLIDER,
                    RaycastContext.FluidHandling.NONE, player));
            if (wall.getType() == HitResult.Type.MISS || wall.getPos().distanceTo(from) >= from.distanceTo(to) - radii[i]) {
                open.add(candidates.get(i));
                openCenters.add(centers[i]);
                openRadii.add(radii[i]);
            }
        }
        double[] r = new double[openRadii.size()];
        for (int i = 0; i < r.length; i++) {
            r[i] = openRadii.get(i);
        }
        int hit = MeleeTarget.pick(eye, look, def.reach(), def.coneHalfAngle(), openCenters.toArray(new double[0][]), r);
        if (hit >= 0) {
            ShotResolver.hitEntity(world, player, def, open.get(hit), look);
        }
    }
}
```
