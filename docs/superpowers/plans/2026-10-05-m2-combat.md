# M2 — Armas, apuntado y disparo: plan de implementación

> **Para quien ejecute el plan:** usar superpowers:subagent-driven-development (recomendado) o superpowers:executing-plans. Los pasos usan casillas (`- [ ]`) para llevar el seguimiento.

**Objetivo:** que CJ lleve un arma real de GTA SA en la mano, apunte hacia donde mira el jugador (clic derecho mantenido) y dispare (clic izquierdo) con la animación, cadencia y cargador de GTA, y que Minecraft marque dónde pega cada disparo (sin daño todavía).

**Arquitectura:** protocolo v2 (el estado lleva el punto de mira, GTA devuelve el arma que sostiene y eventos de disparo). El puente da el arma a CJ y gobierna su tarea de uso de arma de GTA (`CTaskSimpleUseGun`) con un punto objetivo; detecta los disparos mirando el cargador del arma. El mod registra ítems de arma, convierte clics en intenciones, calcula el punto de mira, dibuja el modelo real del arma acoplado a la mano de CJ y marca el impacto con partículas. El conversor extrae los modelos de arma de `gta3.img`.

**Tecnologías:** C++20 (puente, mingw i686 para el `.asi`, clang para las pruebas nativas), Python 3 (protocolo de referencia, conversor, cliente falso), Java 21 con Fabric 1.21.1 (yarn 1.21.1+build.3, Loom 1.17.21).

**Spec:** `docs/superpowers/specs/2026-10-05-m2-combat-design.md` (y el diseño principal `2026-10-05-cj-in-minecraft-design.md`, secciones 4 y 6).

## Desviaciones deliberadas de la spec (se anotan en la spec en la Tarea 1)

Se descubrieron al preparar el plan; ninguna cambia lo que ve el usuario.
1. **Detección de disparos por el cargador, sin gancho en `CWeapon::Fire`.** El puente lee cada frame la munición del cargador del arma activa; si baja, hubo disparos. Evita un *detour* nuevo en código del juego (lo único que se enganchó hasta ahora son llamadas con `call` relativo). Si el cargador no baja en alguna arma, se vuelve al gancho.
2. **El rayo del disparo se resuelve en el cliente en M2.** Solo marca el impacto con partículas, no hace falta el servidor. M3 lo mueve al servidor integrado cuando haya daño y rotura.
3. **La mira es la de Minecraft** (el cursor del centro de la pantalla), que ya es exactamente el punto hacia donde apunta el rayo. No se dibuja una mira propia.
4. **Los modelos de arma salen como `.glb` con una sola articulación** (el hueso de la mano derecha, nodo 24) y matriz de enlace inversa identidad. Así el cargador del mod, el *skinner* y el buffer de poses se reutilizan sin cambios.

## Restricciones globales

- GTA SA 1.0 US, `gta_sa.exe` de 14,383,616 bytes; direcciones de `gta-reversed` verificadas con `tools/verify_exe_addresses.py`.
- UDP en `127.0.0.1`, little-endian, magic `0x434A4D43`. Puertos: GTA escucha en **34560**; Minecraft escucha en **34561**. Cabecera de 8 bytes: `u32 magic`, `u16 version`, `u16 type`. **Versión 2** desde este plan. Tamaños v2: `State` 72, `Echo` 32, `Shot` 24, `Pose` 24 + 32 × N.
- Ejes del modelo de CJ: X adelante, Y izquierda, Z arriba. Conversión GTA→Minecraft `(x,y,z)→(y,z,x)`. Minecraft→GTA `(dx,dy,dz)→(dx,−dz,dy)`.
- Los assets de GTA (`.dff`, `.txd`, `.img`, `.glb`) **nunca entran al repositorio** (`.gitignore` ya lo cubre; `mini.glb` es la única excepción sintética). Las pruebas con datos reales se saltan si no hay instalación.
- Fabric 1.21.1, yarn `1.21.1+build.3`, loader 0.19.5, fabric-api `0.116.17+1.21.1`, Loom 1.17.21, Java 21.
- Documentación y mensajes de commit del proyecto: la documentación en español, el código y los commits en inglés. Cada commit termina con `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- En este entorno la shell es fish: entrecomillar los comodines (`'*.h'`) y no usar `pkill -f` (mata la propia shell); matar procesos por PID.
- Orden de ejecución: Tareas 1–4 en orden. **La Tarea 4 es una puerta**: si falla, se detiene el plan y se informa al usuario (plan B de la spec, sección 2). Las Tareas 5 a 9 pueden ir en cualquier orden entre sí una vez pasada la puerta; la 10 va la última.

## Review Focus

Entradas y fallos que la spec implica y que ninguna tarea tendría por qué probar si no se anotan. Cada línea tiene su prueba en la tarea que se indica.
1. **Un disparo perdido, repetido o con el contador de GTA reiniciado** (GTA se reinicia mientras Minecraft sigue abierto): no se marca dos veces ni se ignora para siempre. → Tarea 5 (`ShotDedup`).
2. **Cambio rápido de ítem, soltar el arma a medias del apuntado o caída de GTA mientras se apunta:** CJ no se queda con el arma ni con la tarea de apuntar colgada. → Tarea 3 (`WeaponDriver`, `BridgeCore`).
3. **Vector de mira nulo, infinito o NaN** (el mod lo manda en cero cuando no hay arma): no se crea ninguna tarea de apuntar. → Tarea 3.
4. **Pantalla abierta (inventario, chat, pausa) con un arma en la mano:** las intenciones salen a cero y el clic no dispara. → Tarea 7 (`ControlsMapper`).
5. **Modelo de arma ausente o corrupto:** se dibuja a CJ sin arma, con un único aviso en el registro, y el render nunca falla. → Tarea 9.

```python
_STATE = struct.Struct("<IIffffffffIIHHfff")  # seq, ts, pos[3], vel[3], yaw, pitch, flags, intents, weapon, pad, aim[3]
_ECHO = struct.Struct("<IIfffHH")  # ack_seq, gta_time_ms, pos[3], weapon_held, pad

STATE_SIZE = _HEADER.size + _STATE.size  # 72
ECHO_SIZE = _HEADER.size + _ECHO.size  # 32
SHOT_SIZE = _HEADER.size + _SHOT.size  # 24
```
```python
@dataclass(frozen=True)
class State:
    seq: int
    ts_ms: int
    pos: tuple
    vel: tuple
    yaw: float
    pitch: float
    flags: int = 0
    intents: int = 0
    weapon: int = 0
    aim: tuple = (0.0, 0.0, 0.0)  # feet -> aim point, Minecraft axes, blocks; (0, 0, 0) = none


@dataclass(frozen=True)
class Echo:
    ack_seq: int
    gta_time_ms: int
    pos: tuple
    weapon_held: int = 0


@dataclass(frozen=True)
class Shot:
    ack_seq: int
    gta_time_ms: int
    shot_seq: int  # total rounds fired since GTA started, including this event's
    weapon: int
    rounds: int    # rounds this event reports
```
```python
def pack_state(s):
    return _HEADER.pack(MAGIC, VERSION, TYPE_STATE) + _STATE.pack(
        s.seq, s.ts_ms, *s.pos, *s.vel, s.yaw, s.pitch, s.flags, s.intents, s.weapon, 0, *s.aim)


def unpack_state(data):
    _check_header(data, TYPE_STATE, STATE_SIZE)
    seq, ts, px, py, pz, vx, vy, vz, yaw, pitch, flags, intents, weapon, _pad, ax, ay, az = _STATE.unpack_from(
        data, _HEADER.size)
    return State(seq, ts, (px, py, pz), (vx, vy, vz), yaw, pitch, flags, intents, weapon, (ax, ay, az))


def pack_echo(e):
    return _HEADER.pack(MAGIC, VERSION, TYPE_ECHO) + _ECHO.pack(e.ack_seq, e.gta_time_ms, *e.pos, e.weapon_held, 0)


def unpack_echo(data):
    _check_header(data, TYPE_ECHO, ECHO_SIZE)
    ack, gta_time, x, y, z, weapon_held, _pad = _ECHO.unpack_from(data, _HEADER.size)
    return Echo(ack, gta_time, (x, y, z), weapon_held)


def pack_shot(s):
    return _HEADER.pack(MAGIC, VERSION, TYPE_SHOT) + _SHOT.pack(s.ack_seq, s.gta_time_ms, s.shot_seq, s.weapon, s.rounds)


def unpack_shot(data):
    _check_header(data, TYPE_SHOT, SHOT_SIZE)
    return Shot(*_SHOT.unpack_from(data, _HEADER.size))
```

#!/usr/bin/env python3
"""A fake Minecraft: sends v2 State packets to the bridge and prints what comes back (held weapon, shots, right hand).

Close Minecraft first: both listen on 127.0.0.1:34561. Examples:
  python3 tools/fake_mc.py --mode held  --weapon 22 --seconds 8   # CJ gets the weapon, no aiming
  python3 tools/fake_mc.py --mode aim   --weapon 22 --seconds 8   # right mouse button held, looking straight ahead
  python3 tools/fake_mc.py --mode sweep --weapon 22 --seconds 12  # aiming while the look direction sweeps up/down and sideways
  python3 tools/fake_mc.py --mode fire  --weapon 22 --seconds 8   # aiming and holding the left mouse button
"""
import argparse
import math
import socket
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent / "protocol"))
import cjproto  # noqa: E402

GTA_ADDR = ("127.0.0.1", 34560)
MC_ADDR = ("127.0.0.1", 34561)
HAND_NODE = 24  # nodeID of the right hand in CJ's skeleton


def look_vector(yaw_deg, pitch_deg):
    """Minecraft's look direction: yaw 0 faces south (+Z), yaw -90 east (+X); pitch -90 is straight up."""
    yaw, pitch = math.radians(yaw_deg), math.radians(pitch_deg)
    return (-math.sin(yaw) * math.cos(pitch), -math.sin(pitch), math.cos(yaw) * math.cos(pitch))


def aim_vector(yaw_deg, pitch_deg, eye_height=1.62, distance=20.0):
    """Feet -> aim point, the way the mod computes it."""
    x, y, z = look_vector(yaw_deg, pitch_deg)
    return (x * distance, eye_height + y * distance, z * distance)


class Scenario:
    MODES = ("idle", "held", "aim", "fire", "sweep")

    def __init__(self, mode, weapon):
        if mode not in self.MODES:
            raise ValueError(f"unknown mode {mode!r}")
        self.mode = mode
        self.weapon = weapon

    def state_at(self, t, seq):
        yaw, pitch = 0.0, 0.0
        weapon, intents, aim = 0, 0, (0.0, 0.0, 0.0)
        if self.mode != "idle":
            weapon = self.weapon
        if self.mode == "sweep":
            yaw = 60.0 * math.sin(t * 0.8)
            pitch = 40.0 * math.sin(t * 1.3)
        if self.mode in ("aim", "fire", "sweep"):
            intents |= cjproto.INTENT_AIM
            aim = aim_vector(yaw, pitch)
        if self.mode == "fire":
            intents |= cjproto.INTENT_FIRE
        return cjproto.State(seq=seq, ts_ms=int(t * 1000) & 0x7FFFFFFF, pos=(0.0, 64.0, 0.0), vel=(0.0, 0.0, 0.0),
                             yaw=yaw, pitch=pitch, flags=cjproto.FLAG_ON_GROUND, intents=intents, weapon=weapon, aim=aim)


def main(argv=None):
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--mode", choices=Scenario.MODES, default="aim")
    ap.add_argument("--weapon", type=int, default=22, help="GTA weapon id: 22 Colt 45, 24 Desert Eagle, 25 shotgun, 28 Uzi, 30 AK-47, 31 M4")
    ap.add_argument("--seconds", type=float, default=8.0)
    args = ap.parse_args(argv)

    rx = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    rx.bind(MC_ADDR)
    rx.settimeout(0.0)
    tx = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    scenario = Scenario(args.mode, args.weapon)

    start = time.monotonic()
    seq, next_send = 0, start
    held, last_report = -1, 0.0
    shots_seen, last_shot_seq = 0, 0
    hand = None
    while True:
        now = time.monotonic()
        t = now - start
        if t > args.seconds:
            break
        if now >= next_send:
            tx.sendto(cjproto.pack_state(scenario.state_at(t, seq)), GTA_ADDR)
            seq += 1
            next_send += 1 / 60
        try:
            while True:
                data = rx.recv(2048)
                try:
                    echo = cjproto.unpack_echo(data)
                    if echo.weapon_held != held:
                        held = echo.weapon_held
                        print(f"[{t:5.2f}s] CJ holds weapon {held}")
                    continue
                except ValueError:
                    pass
                try:
                    shot = cjproto.unpack_shot(data)
                    if shot.shot_seq != last_shot_seq:
                        shots_seen += shot.rounds
                        last_shot_seq = shot.shot_seq
                        print(f"[{t:5.2f}s] SHOT weapon={shot.weapon} rounds={shot.rounds} total={shot.shot_seq}")
                    continue
                except ValueError:
                    pass
                try:
                    pose = cjproto.unpack_pose(data)
                    for bone in pose.bones:
                        if bone.node_id == HAND_NODE:
                            hand = bone.pos
                except ValueError:
                    pass
        except BlockingIOError:
            pass
        if hand and t - last_report >= 1.0:
            last_report = t
            print(f"[{t:5.2f}s] right hand (model space, X fwd / Y left / Z up): "
                  f"{hand[0]:+.2f} {hand[1]:+.2f} {hand[2]:+.2f}")
        time.sleep(0.002)
    print(f"done: {seq} states sent, {shots_seen} rounds reported")
    return 0


if __name__ == "__main__":
    sys.exit(main())

// Whether the simulated pad also presses "aim" (right shoulder) and "fire" (circle) while CJ aims and fires.
// The player's own on-foot task ends a gun task whose pad shows no aiming, so this starts on; the task 4 spike decides.
constexpr bool kGunPad = true;

// Values of the game's eGunCommand. The task keeps the highest command it was given in a frame.
enum class GunCommand : int8_t { None = 0, Aim = 1, Fire = 2, EndNow = 7 };

struct GunPlan {
    bool giveWeapon = false;  // CJ does not hold the weapon yet: give it and select it
    bool takeWeapons = false; // the item was dropped: take away what we gave
    uint16_t weapon = 0;      // the weapon to give
    bool wantTask = false;    // a gun task must exist this frame, aiming at aimTarget with `command`
    bool stopTask = false;    // end the gun task
    GunCommand command = GunCommand::None;
    Vec3 aimTarget{};         // GTA world position
};

// Decides what to do about weapons for each Minecraft state. Pure logic: no game memory, no sockets.
class WeaponDriver {
public:
    static constexpr float kMaxAim = 1000.0f; // blocks; anything longer is not a real aim vector

    void OnState(const StatePacket& s) {
        weapon_ = s.weapon;
        intents_ = s.intents;
        aim_ = {s.aim[0], s.aim[1], s.aim[2]};
    }

    // heldWeapon: the weapon type CJ really holds right now (0 = none).
    GunPlan Plan(Vec3 pedPos, uint16_t heldWeapon) {
        GunPlan p;
        if (weapon_ == 0) {
            if (given_) {
                p.takeWeapons = true;
                given_ = false;
            }
            if (taskActive_) {
                p.stopTask = true;
                taskActive_ = false;
            }
            return p;
        }
        if (heldWeapon != weapon_) {
            p.giveWeapon = true;
            p.weapon = weapon_;
            given_ = true;
            if (taskActive_) {
                p.stopTask = true; // the task belongs to the weapon he held before
                taskActive_ = false;
            }
            return p;
        }
        const bool aiming = (intents_ & kIntentAim) != 0;
        const bool firing = (intents_ & kIntentFire) != 0;
        if ((aiming || firing) && AimUsable()) {
            p.wantTask = true;
            p.command = firing ? GunCommand::Fire : GunCommand::Aim;
            p.aimTarget = pedPos + McDeltaToGta(aim_);
            taskActive_ = true;
        } else if (taskActive_) {
            p.stopTask = true;
            taskActive_ = false;
        }
        return p;
    }

    bool Given() const { return given_; }
    void Reset() { *this = WeaponDriver{}; }

private:
    bool AimUsable() const {
        if (!std::isfinite(aim_.x) || !std::isfinite(aim_.y) || !std::isfinite(aim_.z)) {
            return false;
        }
        const float len2 = aim_.x * aim_.x + aim_.y * aim_.y + aim_.z * aim_.z;
        return len2 > 1e-6f && len2 <= kMaxAim * kMaxAim;
    }

    uint16_t weapon_ = 0;
    uint32_t intents_ = 0;
    Vec3 aim_{};
    bool given_ = false;
    bool taskActive_ = false;
};

// Counts the rounds fired by watching the clip of the active weapon go down. A refill (reload) or a weapon change is not a shot.
class ShotCounter {
public:
    uint16_t Update(uint16_t weapon, uint32_t ammoInClip) {
        uint32_t fired = 0;
        if (have_ && weapon == prevWeapon_ && ammoInClip < prevAmmo_) {
            fired = prevAmmo_ - ammoInClip;
            if (fired > 0xFFFF) {
                fired = 0xFFFF;
            }
        }
        have_ = true;
        prevWeapon_ = weapon;
        prevAmmo_ = ammoInClip;
        total_ += fired;
        return static_cast<uint16_t>(fired);
    }

    uint32_t Total() const { return total_; }
    void Reset() { *this = ShotCounter{}; }

private:
    bool have_ = false;
    uint16_t prevWeapon_ = 0;
    uint32_t prevAmmo_ = 0;
    uint32_t total_ = 0;
};

} // namespace cj

// Calls into the game for guns. Compiled only into the .asi (it dereferences game addresses); everything it
// decides is in weapon_driver.h and tested natively. Every pointer is checked before it is followed.
#include <cstdint>

#include "ped_layout.h"
#include "weapon_driver.h"

namespace cj::gungame {

using GiveFn = int(__attribute__((thiscall)) *)(void* ped, int type, unsigned ammo, bool unused);
using SelectFn = void(__attribute__((thiscall)) *)(void* ped, int type);
using ClearFn = void(__attribute__((thiscall)) *)(void* ped);
using TaskNewFn = void*(__cdecl*)(size_t size);
using UseGunCtorFn = void*(__attribute__((thiscall)) *)(void* task, void* targetEntity, float x, float y, float z,
                                                        int command, int burstLength, int aimImmediate);
using ControlFn = bool(__attribute__((thiscall)) *)(void* task, void* ped, void* targetEntity, int command);
using SetSecondaryFn = void(__attribute__((thiscall)) *)(void* taskManager, void* task, unsigned slot);

constexpr unsigned kInfiniteAmmo = 99999; // above 25 000 the game treats a player's ammo as infinite

inline uint8_t* Intelligence(uint8_t* ped) { return *reinterpret_cast<uint8_t**>(ped + gta::kPedIntelligence); }

// CPedIntelligence::m_pPed must point back at the ped, or the layout assumption is wrong and nothing is touched.
inline uint8_t* TaskManager(uint8_t* ped) {
    uint8_t* intelligence = Intelligence(ped);
    if (!intelligence || *reinterpret_cast<uint8_t**>(intelligence) != ped) {
        return nullptr;
    }
    return intelligence + gta::kIntelligenceTaskMgr;
}

inline uint8_t*& AttackTask(uint8_t* taskManager) {
    return *reinterpret_cast<uint8_t**>(taskManager + gta::kTaskMgrSecondary + 4 * gta::kTaskAttackSlot);
}

inline uint16_t Held(uint8_t* ped) {
    const uint8_t slot = *(ped + gta::kPedActiveSlot);
    if (slot >= gta::kNumWeaponSlots) {
        return 0;
    }
    return static_cast<uint16_t>(*reinterpret_cast<uint32_t*>(ped + gta::kPedWeapons + slot * gta::kWeaponSize + gta::kWeaponType));
}

inline uint32_t AmmoInClip(uint8_t* ped) {
    const uint8_t slot = *(ped + gta::kPedActiveSlot);
    if (slot >= gta::kNumWeaponSlots) {
        return 0;
    }
    return *reinterpret_cast<uint32_t*>(ped + gta::kPedWeapons + slot * gta::kWeaponSize + gta::kWeaponAmmoInClip);
}

    reinterpret_cast<GiveFn>(gta::kGiveWeapon)(ped, weapon, kInfiniteAmmo, false);
    reinterpret_cast<SelectFn>(gta::kSetCurrentWeapon)(ped, weapon);
}

    static void* vtable = nullptr;
    return vtable;

// Makes sure the ped has a CTaskSimpleUseGun in its attack slot, points it at `target` and gives it the command.
// Returns false when the layout does not look right (nothing was done).
inline bool Control(uint8_t* ped, Vec3 target, GunCommand command) {
    uint8_t* manager = TaskManager(ped);
    if (!manager) {
        return false;
    }
    uint8_t* task = AttackTask(manager);
    if (!IsGunTask(task)) {
        void* memory = reinterpret_cast<TaskNewFn>(gta::kTaskNew)(gta::kUseGunSize);
        if (!memory) {
            return false;
        }
        task = static_cast<uint8_t*>(reinterpret_cast<UseGunCtorFn>(gta::kUseGunCtor)(
            memory, nullptr, target.x, target.y, target.z, static_cast<int>(GunCommand::Aim), 1, 0));
        GunVtable() = *reinterpret_cast<void**>(task);
        reinterpret_cast<SetSecondaryFn>(gta::kSetTaskSecondary)(manager, task, gta::kTaskAttackSlot);
    }
    float* where = reinterpret_cast<float*>(task + gta::kUseGunTargetPos);
    where[0] = target.x;
    where[1] = target.y;
    where[2] = target.z;
    reinterpret_cast<ControlFn>(gta::kUseGunControl)(task, ped, nullptr, static_cast<int>(command));
    return true;
}

// Asks the task to end now; the task manager removes it on its next pass.
inline void Stop(uint8_t* ped) {
    uint8_t* manager = TaskManager(ped);
    if (!manager) {
        return;
    }
    uint8_t* task = AttackTask(manager);
    if (IsGunTask(task)) {
        reinterpret_cast<ControlFn>(gta::kUseGunControl)(task, ped, nullptr, static_cast<int>(GunCommand::EndNow));
    }
}

```java
package dev.cjmc;

/**
 * Turns the shot events (each sent twice, maybe lost, maybe from before a GTA restart) into "rounds that are new".
 * shotSeq is the total of rounds GTA has fired, including the event's own; it only ever goes up within one GTA run.
 */
public final class ShotDedup {
    /** A jump back bigger than this means GTA restarted (its counter began again from zero), not a late datagram. */
    private static final int RESTART_JUMP = 1000;

    private boolean started;
    private int last;

    public synchronized int newRounds(int shotSeq, int rounds) {
        if (!started) {
            started = true;
            last = shotSeq - rounds; // the first event counts its own rounds, not the whole history
        }
        int fresh = shotSeq - last; // wraparound-safe
        if (fresh < -RESTART_JUMP) {
            last = shotSeq - rounds; // a restart
            fresh = rounds;
        }
        if (fresh <= 0) {
            return 0;
        }
        last = shotSeq;
        return Math.min(fresh, rounds);
    }
}
```

package dev.cjmc;

/** Pure geometry for drawing a shot's tracer. */
public final class ShotGeometry {
    private ShotGeometry() {}

    /** `count` points along the ray, the first one step in from the origin and the last at `length`. Empty when the ray is not usable. */
    public static double[][] tracerPoints(double[] origin, double[] dir, double length, int count) {
        double len = Math.sqrt(dir[0] * dir[0] + dir[1] * dir[1] + dir[2] * dir[2]);
        if (count <= 0 || !(length > 0) || !(len > 1e-9) || !Double.isFinite(len)) {
            return new double[0][];
        }
        double[][] points = new double[count][3];
        for (int i = 0; i < count; i++) {
            double d = length * (i + 1) / count;
            for (int k = 0; k < 3; k++) {
                points[i][k] = origin[k] + dir[k] / len * d;
            }
        }
        return points;
    }
}

package dev.cjmc;

import java.util.concurrent.ConcurrentLinkedQueue;
import net.minecraft.block.BlockState;
import net.minecraft.client.MinecraftClient;
import net.minecraft.client.network.ClientPlayerEntity;
import net.minecraft.client.world.ClientWorld;
import net.minecraft.entity.projectile.ProjectileUtil;
import net.minecraft.particle.BlockStateParticleEffect;
import net.minecraft.particle.ParticleTypes;
import net.minecraft.util.hit.BlockHitResult;
import net.minecraft.util.hit.EntityHitResult;
import net.minecraft.util.hit.HitResult;
import net.minecraft.util.math.Box;
import net.minecraft.util.math.Vec3d;
import net.minecraft.world.RaycastContext;

/**
 * M2: marks where each shot lands. The network thread queues the rounds; the client tick throws one ray per round from the
 * player's eyes (not from the barrel GTA draws) and spawns particles: a tracer along the ray and an impact where it ends.
 * No damage yet (M3).
 */
public final class ShotEffects {
    public static final ShotEffects INSTANCE = new ShotEffects();
    private static final double RANGE = 100.0;
    private static final int TRACER_POINTS = 12;
    private static final int MAX_ROUNDS_PER_TICK = 8;

    private final ShotDedup dedup = new ShotDedup();
    private final ConcurrentLinkedQueue<Boolean> pending = new ConcurrentLinkedQueue<>();

    private ShotEffects() {}

    /** Called from the network thread. */
    public void onShot(Protocol.Shot shot) {
        int rounds = dedup.newRounds(shot.shotSeq(), shot.rounds());
        for (int i = 0; i < rounds && pending.size() < 64; i++) {
            pending.add(Boolean.TRUE);
        }
    }

    /** Called from the client thread every tick. */
    public void tick(MinecraftClient client) {
        ClientPlayerEntity player = client.player;
        ClientWorld world = client.world;
        if (player == null || world == null) {
            pending.clear();
            return;
        }
        for (int i = 0; i < MAX_ROUNDS_PER_TICK && pending.poll() != null; i++) {
            fire(player, world);
        }
    }

    private void fire(ClientPlayerEntity player, ClientWorld world) {
        Vec3d eye = player.getCameraPosVec(1.0f);
        Vec3d look = player.getRotationVec(1.0f);
        Vec3d end = eye.add(look.multiply(RANGE));

        BlockHitResult block = world.raycast(new RaycastContext(eye, end, RaycastContext.ShapeType.OUTLINE,
                RaycastContext.FluidHandling.NONE, player));
        double blockDistance = block.getType() == HitResult.Type.MISS ? Double.POSITIVE_INFINITY : block.getPos().distanceTo(eye);
        Box search = new Box(eye, end).expand(1.0);
        EntityHitResult entity = ProjectileUtil.raycast(player, eye, end, search,
                e -> !e.isSpectator() && e.canHit(), RANGE * RANGE);
        double entityDistance = entity == null ? Double.POSITIVE_INFINITY : entity.getPos().distanceTo(eye);

        double reach = Math.min(Math.min(blockDistance, entityDistance), RANGE);
        Vec3d muzzle = eye.add(look.multiply(0.6)).add(0, -0.25, 0);
        double[][] points = ShotGeometry.tracerPoints(new double[] {muzzle.x, muzzle.y, muzzle.z},
                new double[] {look.x, look.y, look.z}, reach - 0.6, TRACER_POINTS);
        for (double[] p : points) {
            world.addParticle(ParticleTypes.END_ROD, p[0], p[1], p[2], 0, 0, 0);
        }
        if (entityDistance < blockDistance) {
            Vec3d at = entity.getPos();
            for (int i = 0; i < 6; i++) {
                world.addParticle(ParticleTypes.CRIT, at.x, at.y, at.z,
                        (world.random.nextDouble() - 0.5) * 0.4, world.random.nextDouble() * 0.3, (world.random.nextDouble() - 0.5) * 0.4);
            }
        } else if (blockDistance < RANGE) {
            BlockState state = world.getBlockState(block.getBlockPos());
            Vec3d at = block.getPos();
            for (int i = 0; i < 8; i++) {
                world.addParticle(new BlockStateParticleEffect(ParticleTypes.BLOCK, state), at.x, at.y, at.z,
                        (world.random.nextDouble() - 0.5) * 0.4, world.random.nextDouble() * 0.3, (world.random.nextDouble() - 0.5) * 0.4);
            }
        }
    }
}

```java
package dev.cjmc;

import com.google.gson.JsonArray;
import com.google.gson.JsonElement;
import com.google.gson.JsonObject;
import com.google.gson.JsonParser;
import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

/** The weapons the mod knows, read from weapons.json. damage, range, pellets, spread and blockPower are used from M3 on. */
public final class WeaponCatalog {
    public record WeaponDef(String id, String name, int gta, String model, float[] holdOffset, float[] holdRotation,
                            float damage, float range, int pellets, float spread, float blockPower) {}

    private final List<WeaponDef> defs;

    private WeaponCatalog(List<WeaponDef> defs) {
        this.defs = List.copyOf(defs);
    }

    public List<WeaponDef> all() {
        return defs;
    }

    public WeaponDef byId(String id) {
        for (WeaponDef d : defs) {
            if (d.id().equals(id)) {
                return d;
            }
        }
        return null;
    }

    public WeaponDef byGta(int gta) {
        for (WeaponDef d : defs) {
            if (d.gta() == gta) {
                return d;
            }
        }
        return null;
    }

    public static WeaponCatalog load() {
        try (InputStream in = WeaponCatalog.class.getResourceAsStream("/weapons.json")) {
            if (in == null) {
                throw new IllegalStateException("weapons.json is missing from the mod");
            }
            return parse(new String(in.readAllBytes(), StandardCharsets.UTF_8));
        } catch (IOException e) {
            throw new IllegalStateException("weapons.json could not be read", e);
        }
    }

    public static WeaponCatalog parse(String json) {
        try {
            JsonObject root = JsonParser.parseString(json).getAsJsonObject();
            JsonArray array = root.getAsJsonArray("weapons");
            if (array == null) {
                throw new IllegalArgumentException("weapons.json has no \"weapons\" list");
            }
            List<WeaponDef> out = new ArrayList<>();
            Set<String> ids = new HashSet<>();
            Set<Integer> gtaIds = new HashSet<>();
            for (JsonElement e : array) {
                JsonObject o = e.getAsJsonObject();
                WeaponDef d = new WeaponDef(text(o, "id"), text(o, "name"), (int) number(o, "gta"), text(o, "model"),
                        vec3(o, "holdOffset"), vec3(o, "holdRotation"), number(o, "damage"), number(o, "range"),
                        (int) number(o, "pellets"), number(o, "spread"), number(o, "blockPower"));
                if (d.gta() <= 0 || d.gta() > 0xFFFF) {
                    throw new IllegalArgumentException("weapon " + d.id() + " has the GTA id " + d.gta());
                }
                if (!ids.add(d.id())) {
                    throw new IllegalArgumentException("duplicate weapon id " + d.id());
                }
                if (!gtaIds.add(d.gta())) {
                    throw new IllegalArgumentException("duplicate GTA weapon id " + d.gta());
                }
                out.add(d);
            }
            return new WeaponCatalog(out);
        } catch (IllegalArgumentException e) {
            throw e;
        } catch (RuntimeException e) { // a wrong type, malformed JSON...
            throw new IllegalArgumentException("weapons.json is malformed (" + e + ")", e);
        }
    }

    private static String text(JsonObject o, String key) {
        JsonElement e = o.get(key);
        if (e == null || !e.isJsonPrimitive()) {
            throw new IllegalArgumentException("a weapon is missing \"" + key + "\"");
        }
        return e.getAsString();
    }

    private static float number(JsonObject o, String key) {
        JsonElement e = o.get(key);
        if (e == null || !e.isJsonPrimitive()) {
            throw new IllegalArgumentException("a weapon is missing \"" + key + "\"");
        }
        return e.getAsFloat();
    }

    private static float[] vec3(JsonObject o, String key) {
        JsonElement e = o.get(key);
        if (e == null || !e.isJsonArray() || e.getAsJsonArray().size() != 3) {
            throw new IllegalArgumentException("\"" + key + "\" needs three numbers");
        }
        JsonArray a = e.getAsJsonArray();
        return new float[] {a.get(0).getAsFloat(), a.get(1).getAsFloat(), a.get(2).getAsFloat()};
    }
}

package dev.cjmc;

/** The aim vector the State packet carries: from the player's feet to the point the crosshair is on. */
public final class AimRay {
    public static final float MIN_DISTANCE = 2f;
    public static final float MAX_DISTANCE = 50f;

    private AimRay() {}

    /**
     * @param hitDistance distance from the eyes to what the crosshair hits; NaN, zero or negative when it hits nothing
     * @return the vector in Minecraft axes, or (0, 0, 0) ("no aim") when an input is not finite
     */
    public static float[] aimVector(double[] feet, double[] eye, double[] look, double hitDistance) {
        for (int k = 0; k < 3; k++) {
            if (!Double.isFinite(feet[k]) || !Double.isFinite(eye[k]) || !Double.isFinite(look[k])) {
                return new float[] {0, 0, 0};
            }
        }
        double distance = hitDistance > 0 ? hitDistance : MAX_DISTANCE; // NaN fails the comparison too
        distance = Math.max(MIN_DISTANCE, Math.min(MAX_DISTANCE, distance));
        float[] out = new float[3];
        for (int k = 0; k < 3; k++) {
            out[k] = (float) (eye[k] - feet[k] + look[k] * distance);
        }
        return out;
    }
}

def _rgb565(c):
    r, g, b = (c >> 11) & 31, (c >> 5) & 63, c & 31
    return (r << 3) | (r >> 2), (g << 2) | (g >> 4), (b << 3) | (b >> 2)


def _alpha5(a0, a1, i):
    if i == 0:
        return a0
    if i == 1:
        return a1
    if a0 > a1:
        return ((8 - i) * a0 + (i - 1) * a1) // 7
    if i == 6:
        return 0
    if i == 7:
        return 255
    return ((6 - i) * a0 + (i - 1) * a1) // 5


def decode_dxt(data, width, height, fourcc):
    """DXT1 / DXT3 / DXT5 (BC1 / BC2 / BC3) to RGBA bytes, top row first. Cropped to width x height."""
    block_size = 8 if fourcc == DXT1 else 16
    bw, bh = (width + 3) // 4, (height + 3) // 4
    if len(data) < bw * bh * block_size:
        raise FormatError(f"compressed texture data is {len(data)} bytes, {bw * bh * block_size} needed")
    out = bytearray(width * height * 4)
    for by in range(bh):
        for bx in range(bw):
            off = (by * bw + bx) * block_size
            color_off = off if fourcc == DXT1 else off + 8
            c0, c1, bits = struct.unpack_from("<HHI", data, color_off)
            p0, p1 = _rgb565(c0), _rgb565(c1)
            if c0 > c1 or fourcc != DXT1:
                palette = [p0 + (255,), p1 + (255,),
                           tuple((2 * a + b) // 3 for a, b in zip(p0, p1)) + (255,),
                           tuple((a + 2 * b) // 3 for a, b in zip(p0, p1)) + (255,)]
            else:
                palette = [p0 + (255,), p1 + (255,), tuple((a + b) // 2 for a, b in zip(p0, p1)) + (255,), (0, 0, 0, 0)]
            if fourcc == DXT3:
                alpha_bits = struct.unpack_from("<Q", data, off)[0]
            elif fourcc == DXT5:
                a0, a1 = data[off], data[off + 1]
                alpha_bits = int.from_bytes(data[off + 2:off + 8], "little")
            for py in range(4):
                y = by * 4 + py
                if y >= height:
                    break
                for px in range(4):
                    x = bx * 4 + px
                    if x >= width:
                        break
                    n = py * 4 + px
                    r, g, b, a = palette[(bits >> (2 * n)) & 3]
                    if fourcc == DXT3:
                        a = ((alpha_bits >> (4 * n)) & 15) * 17
                    elif fourcc == DXT5:
                        a = _alpha5(a0, a1, (alpha_bits >> (3 * n)) & 7)
                    o = (y * width + x) * 4
                    out[o:o + 4] = bytes((r, g, b, a))
    return bytes(out)
```

@dataclass(frozen=True)
class StaticPart:
    positions: list
    normals: list
    uvs: list
    triangles: list
    texture: str  # name of the texture of its material


def _frames(data, clump):
    st = first(data, first(data, clump, FRAME_LIST), STRUCT)
    count = struct.unpack_from("<I", data, st.start)[0]
    frames = []
    for i in range(count):
        values = struct.unpack_from("<12f", data, st.start + 4 + i * 56)
        parent = struct.unpack_from("<i", data, st.start + 4 + i * 56 + 48)[0]
        frames.append((parent, values))
    return frames


def _texture_name(data, geometry):
    names = set()
    for material in all_of(data, first(data, geometry, MATERIAL_LIST), MATERIAL):
        for texture in all_of(data, material, TEXTURE):
            raw = first(data, texture, STRING)
            names.add(data[raw.start:raw.end].split(b"\0")[0].decode("ascii", "replace"))
    if not names:
        raise FormatError("the geometry has no textured material")
    if len(names) > 1:
        raise FormatError(f"the geometry uses {len(names)} textures ({', '.join(sorted(names))}); only one is supported")
    return names.pop()


def parse_static_part(data):
    """The solid geometry of a model with no skeleton (a weapon): the atomic that hangs from the root frame.
    The muzzle flash is another atomic on a child frame and is left out."""
    clump = first(data, root(data), CLUMP)
    frames = _frames(data, clump)
    geometries = all_of(data, first(data, clump, GEOMETRY_LIST), GEOMETRY)
    for atomic in all_of(data, clump, ATOMIC):
        st = first(data, atomic, STRUCT)
        frame, geometry = struct.unpack_from("<II", data, st.start)
        if frame < len(frames) and frames[frame][0] == -1 and geometry < len(geometries):
            values = frames[frame][1]
            identity = (1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0)
            if any(abs(v - e) > 1e-4 for v, e in zip(values, identity)):
                raise FormatError("the root frame of the model is not the identity; the model would need a transform")
            positions, normals, uvs, triangles, _count = _read_geometry(data, geometries[geometry], allow_tristrip=True)
            return StaticPart(positions, normals, uvs, triangles, _texture_name(data, geometries[geometry]))
    raise FormatError("no geometry hangs from the root frame")

    puts the weapon in it. Vertices are the weapon's own, in its model space."""

    except FormatError as e:
        raise ConversionError(f"{name}: {e}") from e

    except FormatError as e:

package dev.cjmc;

/** Puts a weapon in CJ's right hand: the hand's pose, shifted and turned by the weapon's hold (set per weapon in weapons.json). */
public final class WeaponAttach {
    private WeaponAttach() {}

    /** Rotation of rxDeg about X, then ryDeg about Y, then rzDeg about Z, all about fixed axes: q = qz * qy * qx. Returns (x, y, z, w). */
    public static float[] euler(float rxDeg, float ryDeg, float rzDeg) {
        float[] qx = axisAngle(1, 0, 0, rxDeg);
        float[] qy = axisAngle(0, 1, 0, ryDeg);
        float[] qz = axisAngle(0, 0, 1, rzDeg);
        return mul(qz, mul(qy, qx));
    }

    private static float[] axisAngle(float x, float y, float z, float deg) {
        double half = Math.toRadians(deg) / 2;
        float s = (float) Math.sin(half);
        return new float[] {x * s, y * s, z * s, (float) Math.cos(half)};
    }

    /** Hamilton product a * b of two quaternions (x, y, z, w). */
    static float[] mul(float[] a, float[] b) {
        return new float[] {
                a[3] * b[0] + a[0] * b[3] + a[1] * b[2] - a[2] * b[1],
                a[3] * b[1] - a[0] * b[2] + a[1] * b[3] + a[2] * b[0],
                a[3] * b[2] + a[0] * b[1] - a[1] * b[0] + a[2] * b[3],
                a[3] * b[3] - a[0] * b[0] - a[1] * b[1] - a[2] * b[2]};
    }

    /** out = q * v, for a unit quaternion q. */
    static void rotate(float[] q, float[] v, float[] out) {
        float tx = 2 * (q[1] * v[2] - q[2] * v[1]);
        float ty = 2 * (q[2] * v[0] - q[0] * v[2]);
        float tz = 2 * (q[0] * v[1] - q[1] * v[0]);
        out[0] = v[0] + q[3] * tx + (q[1] * tz - q[2] * ty);
        out[1] = v[1] + q[3] * ty + (q[2] * tx - q[0] * tz);
        out[2] = v[2] + q[3] * tz + (q[0] * ty - q[1] * tx);
    }

    /**
     * Fills joint 0 of `out` (a one-joint frame, the weapon's own) with the pose of the weapon: the pose of CJ's hand joint
     * `handJoint`, then `offset` and `rotationDeg` in the hand's own frame. out.has[0] is false when CJ's frame has no hand.
     */
    public static void handFrame(JointFrame cj, int handJoint, float[] offset, float[] rotationDeg, JointFrame out) {
        if (handJoint < 0 || handJoint >= cj.has.length || !cj.has[handJoint]) {
            out.has[0] = false;
            return;
        }
        float[] hq = {cj.quat[4 * handJoint], cj.quat[4 * handJoint + 1], cj.quat[4 * handJoint + 2], cj.quat[4 * handJoint + 3]};
        float[] shift = new float[3];
        rotate(hq, offset, shift);
        out.pos[0] = cj.pos[3 * handJoint] + shift[0];
        out.pos[1] = cj.pos[3 * handJoint + 1] + shift[1];
        out.pos[2] = cj.pos[3 * handJoint + 2] + shift[2];
        float[] q = mul(hq, euler(rotationDeg[0], rotationDeg[1], rotationDeg[2]));
        float len = (float) Math.sqrt(q[0] * q[0] + q[1] * q[1] + q[2] * q[2] + q[3] * q[3]);
        for (int k = 0; k < 4; k++) {
            out.quat[k] = q[k] / len;
        }
        out.has[0] = true;
    }
}

/** Submits one skinned part to the entity pass. Triangles go out as quads whose last vertex is repeated: the entity layers draw quads. */
final class MeshEmitter {
    private MeshEmitter() {}

    static void emit(MatrixStack.Entry entry, VertexConsumerProvider vcp, GlbModel.Part part, float[] pos, float[] nrm,
                     int light, Identifier texture) {
        VertexConsumer out = vcp.getBuffer(RenderLayer.getEntityCutoutNoCull(texture));

package dev.cjmc;

import java.nio.file.Path;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;
import net.minecraft.client.MinecraftClient;
import net.minecraft.client.render.VertexConsumerProvider;
import net.minecraft.client.texture.NativeImage;
import net.minecraft.client.texture.NativeImageBackedTexture;
import net.minecraft.client.util.math.MatrixStack;
import net.minecraft.util.Identifier;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

/** Draws the weapon in CJ's hand. Render thread only. A weapon whose model cannot be loaded is drawn as nothing, with one log line. */
final class WeaponRig {
    private static final Logger LOG = LoggerFactory.getLogger("cj_fabric");

    private record Loaded(GlbModel model, Skinner skinner, List<Identifier> textures) {}

    private final Path dir;
    private final Map<String, Loaded> loaded = new HashMap<>();
    private final Set<String> failed = new HashSet<>();
    private final JointFrame frame = new JointFrame(1);
    private volatile Map<String, float[]> overrides = Map.of();

    WeaponRig(Path dir) {
        this.dir = dir;
    }

    /** Replaces the hold (offset xyz, rotation xyz in degrees) of one weapon until the game closes: for calibrating by eye. */
    void setHold(String weaponId, float[] six) {
        Map<String, float[]> copy = new HashMap<>(overrides);
        copy.put(weaponId, six.clone());
        overrides = copy;
    }

    void draw(WeaponCatalog.WeaponDef def, JointFrame cj, int handJoint, float groundOffset, MatrixStack.Entry entry,
              VertexConsumerProvider vcp, int light) {
        Loaded l = get(def.model());
        if (l == null) {
            return;
        }
        float[] hold = overrides.get(def.id());
        float[] offset = hold != null ? new float[] {hold[0], hold[1], hold[2]} : def.holdOffset();
        float[] rotation = hold != null ? new float[] {hold[3], hold[4], hold[5]} : def.holdRotation();
        WeaponAttach.handFrame(cj, handJoint, offset, rotation, frame);
        if (!frame.has[0]) {
            return;
        }
        l.skinner().skin(frame, groundOffset);
        for (int p = 0; p < l.model().parts.size(); p++) {
            GlbModel.Part part = l.model().parts.get(p);
            MeshEmitter.emit(entry, vcp, part, l.skinner().positions[p], l.skinner().normals[p], light, l.textures().get(part.image()));
        }
    }

    private Loaded get(String model) {
        Loaded l = loaded.get(model);
        if (l != null || failed.contains(model)) {
            return l;
        }
        WeaponModelLoader.Result r = WeaponModelLoader.read(dir.resolve(model + ".glb"));
        if (r.model() == null) {
            failed.add(model);
            LOG.warn("weapon model not drawn: {}", r.problem());
            return null;
        }
        try {
            List<Identifier> textures = new ArrayList<>();
            MinecraftClient client = MinecraftClient.getInstance();
            for (int i = 0; i < r.model().images.size(); i++) {
                NativeImage image = NativeImage.read(new java.io.ByteArrayInputStream(r.model().images.get(i)));
                Identifier id = Identifier.of("cj_fabric", "weapon/" + model + "/" + i);
                client.getTextureManager().registerTexture(id, new NativeImageBackedTexture(image));
                textures.add(id);
            }
            l = new Loaded(r.model(), new Skinner(r.model()), textures);
            loaded.put(model, l);
            LOG.info("loaded weapon model {}", model);
            return l;
        } catch (java.io.IOException | RuntimeException e) {
            failed.add(model);
            LOG.warn("weapon model {} not drawn: its texture is unreadable: {}", model, e.getMessage());
            return null;
        }
    }
}
